## en

- Sessions now opens inside Messages, with a draggable split and visibility, side and proportions remembered per Channel. Existing layouts and shortcuts migrate; the Sessions shortcut restores a hidden Messages panel. Right-click the Messages header to manage subpanel switch visibility. Groups do not expose Bot-only Memory files, Memory evolution, Schedules, Browser or Computer controls ([#2049](https://github.com/BotHarness/DeepSeekBot/issues/2049)).

## zh

- 会话现作为消息面板内的子面板显示，支持拖拽分割，并按频道记住开关、方向与比例。旧布局和快捷键保留迁移；会话快捷键可恢复隐藏的消息父面板。右键消息 header 可管理子面板开关显隐。群聊不显示 Bot 专属的记忆文件、记忆演化、定时任务、浏览器与电脑控制入口（[#2049](https://github.com/BotHarness/DeepSeekBot/issues/2049)）。
