## en

- Mobile text and inputs use iOS semantic Dynamic Type and Android native scaling, with scrolling filter headings, compact usage summaries and bounded draft fields. Layouts reflow when the system text size changes, with growing controls, readable button labels and a search field that has room for accessibility sizes ([#2004](https://github.com/BotHarness/DeepSeekBot/issues/2004)).

## zh

- 手机端文字和输入框遵循 iOS 语义动态字号与 Android 原生缩放，筛选标题可滚动，用量摘要更紧凑，长草稿在有限高度内滚动。界面随系统字号变化重新排版，控件随内容增长，按钮标签可换行，搜索框为辅助功能大字号留出空间（[#2004](https://github.com/BotHarness/DeepSeekBot/issues/2004)）。
