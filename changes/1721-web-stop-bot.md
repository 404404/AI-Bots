## en

- Stop a PersonaBot from the Web Client too. While a Bot in the DM or Group Channel is thinking or working and the composer is empty, the Send button becomes **Stop**; pressing it ends that Bot's current turn, the same as the mobile Stop. In a Group Channel it stops every Bot that is working there. Start typing and the button turns back into Send, so you can still steer the Bot instead ([#1721](https://github.com/BotHarness/DeepSeekBot/issues/1721)).

## zh

- Web 客户端也能停止 PersonaBot。私聊或群组频道里有 Bot 在思考或工作、且输入框为空时，发送按钮会变成 **停止**，按下后结束该 Bot 当前这一轮，与手机端的停止相同。在群组频道里会停止所有正在工作的 Bot。开始输入后按钮变回发送，你仍可以改为发消息引导 Bot（[#1721](https://github.com/BotHarness/DeepSeekBot/issues/1721)）。
