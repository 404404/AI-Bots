## en

- An agent can now set a Bot's avatar, banner, pixel appearance, primary color, wake policy per source and standing limits, arrange the sidebar (sections, order, pins, hidden), set the Human's names, turn developer mode on or off and manage the Custom Part Library from the `deepseekbot` CLI against a running Host, through the same Host checks as the Web UI ([#1702](https://github.com/BotHarness/DeepSeekBot/issues/1702)).

## zh

- Agent 现在可以用 `deepseekbot` 命令行连接运行中的 Host，设置 Bot 的头像、横幅、像素外观、主色、各来源的唤醒策略和常驻上限，整理侧边栏（分组、顺序、置顶、隐藏），设置人类的名字，开关开发者模式，并管理自定义部件库；这些命令与 Web 界面经过同样的 Host 检查（[#1702](https://github.com/BotHarness/DeepSeekBot/issues/1702)）。
