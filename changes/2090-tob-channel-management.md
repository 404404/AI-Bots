## en

- Tob can create groups and add existing Bots through reviewed CLI operations. Invited Bots join immediately by default after management approval; an existing auto-accept opt-out is preserved. Stable operation keys recover the original group or invitation after a lost response, and Tob stays outside managed groups ([#2090](https://github.com/BotHarness/DeepSeekBot/issues/2090), [CLI guide](../docs/bot-cli.md#tob-group-creation-and-invitations)).

## zh

- Tob 可通过经审核的 CLI 操作建群并加入现有 Bot。管理审批通过后，受邀 Bot 默认立即入群；已关闭自动接受的选择仍被保留。响应丢失后，稳定操作标识可核对原群或邀请，Tob 自身不加入受管理群聊（[#2090](https://github.com/BotHarness/DeepSeekBot/issues/2090)、[CLI 指南](../docs/bot-cli.md#tob-group-creation-and-invitations)）。
