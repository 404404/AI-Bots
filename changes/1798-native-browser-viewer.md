## en

- In the DeepSeekBot mobile app, a Bot's profile now has a **Browser** button when the Bot has Browser Access. It opens the Bot's Browser on a native screen: watch it live, pinch to zoom, then **Pause Bot** to take over by tapping where you touch or using trackpad mode, scroll, and type with the phone keyboard. **Resume** hands it back. The new `deepseekbot browser-input` command sends the same input from a terminal ([#1798](https://github.com/BotHarness/DeepSeekBot/issues/1798)).

## zh

- DeepSeekBot 手机 App 里，开启了浏览器权限的 Bot 的资料页现在有**浏览器**按钮，会在原生界面打开 Bot 的浏览器：可以实时观看、双指缩放，点**暂停 Bot** 后接管，支持直接点按或触控板模式、滚动，以及用手机键盘输入；点**继续**交还给 Bot。新的 `deepseekbot browser-input` 命令可以在终端发送同样的操作（[#1798](https://github.com/BotHarness/DeepSeekBot/issues/1798)）。
