## en

- In the DeepSeekBot mobile app, tapping the Bot's name at the top of a DM opens its profile: avatar, name, Bot Tags and Bot Bio, with Message, Computer and Notifications buttons. Below them you can read the Bot's Soul, its Memory repository as a folder tree you can open folder by folder and file by file, its schedules, the group Channels it is in and the folders shared with it. Editing stays on the computer for now ([#1643](https://github.com/BotHarness/DeepSeekBot/issues/1643)).

## zh

- DeepSeekBot 手机 App 里，点私聊顶部的 Bot 名字会打开它的资料页：头像、名字、Bot 标签和 Bot 简介，以及「发消息」「电脑」「通知」按钮。下面可以查看 Bot 的 Soul、以文件夹树呈现的记忆仓库（可以逐层打开文件夹和文件）、定时任务、所在的群聊频道和共享给它的文件夹。暂时只能查看，编辑仍在电脑上完成（[#1643](https://github.com/BotHarness/DeepSeekBot/issues/1643)）。
