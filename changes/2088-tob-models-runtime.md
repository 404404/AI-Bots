## en

- Tob can use the DeepSeekBot CLI to manage Host and per-Bot models, model presets, live runtime preferences, telemetry, Git installation and reviewed release operations, preserving existing owners, approval, revision guards and private credential setup ([#2088](https://github.com/BotHarness/DeepSeekBot/issues/2088), [CLI guide](../docs/bot-cli.md#tob-model-and-runtime-management)).

- Ordinary capability questions now discover the installed CLI and explain supported actions without proposing changes; runtime instructions and CLI entries ship with the plugin ([#2088](https://github.com/BotHarness/DeepSeekBot/issues/2088)).

## zh
