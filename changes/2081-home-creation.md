## en

- Bot creation opens inside Home from the Channels (+) entry. Blank creation needs only a name, optional details stay folded, and returning to Home keeps creation/import drafts until success. GitHub and ZIP imports continue using the existing owners ([#2081](https://github.com/BotHarness/DeepSeekBot/issues/2081)).

## zh
