## en

- Ask a PersonaBot in chat to create another PersonaBot. It fills in the name, Bio, Tags, Avatar, Soul and Core Memory from the conversation and can place the new Bot's Memory in a folder you name. The call follows the same tool approval and saved rules as other Bot tools; when it asks you, the card previews the new Bot and its Memory folder. The new Bot appears in the sidebar with its DM, and `deepseekbot create` gains `--avatar-file` and `--core-memory` ([#1858](https://github.com/BotHarness/DeepSeekBot/issues/1858)).

## zh

- 现在可以在聊天中让 PersonaBot 帮你创建另一个 PersonaBot。它会根据对话填好名称、简介、标签、头像、Soul 和核心记忆，也可以把新 Bot 的记忆放在你指定的文件夹。这次调用与其他 Bot 工具一样遵循工具审批和已保存的规则；需要你确认时，卡片会预览新 Bot 及其记忆文件夹。新 Bot 会带着私聊出现在侧边栏，`deepseekbot create` 也新增了 `--avatar-file` 和 `--core-memory`（[#1858](https://github.com/BotHarness/DeepSeekBot/issues/1858)）。
