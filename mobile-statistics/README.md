## A 这次界面怎样改

新安装的匿名统计默认开启。已有用户主动关闭的选择会保留。开关只放在设置页最底部，配对页不再显示。

详细说明默认收起。点击“了解匿名统计”展开，再点击可以收起。保存失败的提示始终可见。

| 情况 | 行为 |
| --- | --- |
| 全新安装 | 使用开启默认值 |
| 已保存关闭选择 | 保持关闭 |
| 读取设置失败 | 暂停统计，不覆盖旧选择 |
| 用户关闭统计 | 中止上传，清除本机标识和待发事件 |

首次开启使用时，显示一次匿名统计说明，提供隐私说明、源码、打开设置和“知道了”。关闭提示会保存，重启后不重复出现。与 Web 相同，默认统计不等待点击“知道了”；它是说明提示，并非条款同意门禁。本次没有开启生产收集配置。

## B 数据怎样到 PostHog

```flow
配对与聊天模块 -> 手机统计模块: 已确认结果
手机统计模块 -> 配置与本机开关检查
配置与本机开关检查 -> 白名单队列
白名单队列 -> 官方 React Native SDK
官方 React Native SDK -> 出口字段检查
出口字段检查 -> 自有代理
自有代理 -> PostHog
```

手机统计模块属于应用自身。配对、Host client 和 Conversation 继续拥有产品行为。统计代码不接管 Host 权限，也不使用带设备凭证的请求。

官方 SDK 只负责传输。自动页面、触摸、生命周期、异常和回放采集关闭。远程配置、功能旗标和问卷请求也关闭。

## C 哪些结果才算数

| 事件 | 确认条件 |
| --- | --- |
| 配对成功 | 兑换成功，且手机保存 Host 成功 |
| 连接就绪 | 认证后取得可用的实时 Roster |
| 首次发送 | Host 接受发送，或同一消息得到日志确认 |
| 观察 Bot 消息 | 已接受发送后，前台聊天出现新的已提交消息 |

乐观气泡、缓存历史和流式草稿都不算成功。发送后离开页面，Host 接受仍会被记录。隐藏页面中的 Bot 消息不会推进观察步骤。

连接观察在 30 秒结束，但不会停止产品重连。后续恢复记为新的一次观察。拒绝原因只使用固定的设备凭证分类。

## D 隐私与失败边界

```limits
队列数量 | max 100 | 条
队列大小 | max 256 | KiB
队列有效期 | max 24 | 小时
单次发送等待 | max 8 | 秒
```

事件不包含聊天内容、文件、配对链接、凭证或产品标识。重试保留原事件 UUID，发送完成后清空 SDK 队列。安装标识不与网站、账号或电脑关联。

关闭会清除本机标识和未发送事件，不能撤回服务端已收到的数据。系统备份可能恢复已保存的选择和标识。保存失败会暂停本次运行的统计并提示重试。

网络链路会接触 IP。已核实项目 648269 的 IP 丢弃设置开启。该设置不能证明原生事件已送达。
