## 二、简介（B 站上限 2000 字，下面约 600 字）

```
DeepSeekBot 是开源的 GrokBot / ChatGPT Dots 平替，基于 DeepSeek Harness（DSH）生态，直接用 DSH 自己的 session 管理和 Harness，所以 DSH 能接的模型服务商（LLM Provider）它都能用；以一个 DSH 插件的形式安装，可以和你已有的其他 DSH 插件一起用（遇到不兼容的欢迎提 Issue 或 PR）。MIT 开源。

它不是「又一个聊天框」，而是一组有各自身份、人格和记忆的 bots：
· 像找同事一样给 bot 发消息、派活儿；在 Group 里 @ 谁谁就接话，几个 bot 可以同时开工
· 对人不对事：建一个虚拟伙伴、虚拟员工，有事直接找它，不用自己管 session
· 住进飞书 / Lark、Slack、Discord 和微信，每个 bot 用自己的身份出现在你的团队里，被 @ 时在原话题里回复
· 记忆就是 Git：偏好、项目、聊过的话都存成看得见的文件，分支、提交历史、diff 随时打开；记错了能回到过去；还能推到 GitHub，在多台机器之间共享同一份记忆
· 授权工作区后，bot 能把任务拆成独立的 Assignment 委派出去，各自出报告
· 像素头像由名字生成，工作时会一颗像素一颗像素地变成它正在用的工具

🔗 官网：https://go.botharness.ai/bili
🔗 GitHub：https://github.com/BotHarness/BotHarness
🔗 像素头像引擎（独立开源）：https://github.com/BotHarness/BotPixel
🔗 文档：https://go.botharness.ai/bili-docs

一句话安装：打开 DeepSeek Harness 桌面端，点「插件 → 添加插件」，在「包名或地址」里输入 deepseekbot，点「安装」。
安装教程：https://go.botharness.ai/bili-install

开发者（命令行）：
npm i -g @deepseek-ai/dsh@0.2.0-rc.1
dsh plugin --profile web add deepseekbot
dsh web

欢迎试用、提 Issue、点 Star ⭐
QQ 交流群：1125565676

BGM：《如果我是 AI》（原创歌词，AI 生成）
```
