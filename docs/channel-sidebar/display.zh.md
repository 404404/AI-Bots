# 显示与布局

在 Bot 私聊或本地群中，打开 **Channel sidebar**，点击齿轮 **Channel sidebar 设置**。第一项 **频道设置…** 打开这个聊天的[频道设置](/zh/docs/channel-sidebar#按功能查看教程)弹窗；其余控件改变展示，不改变 Bot 模型、记忆内容或执行权限。

## 宽度与标签页

- 拖动侧栏左边的分隔线调整宽度。默认 **320 px**，范围 **260–560 px**。
- 聚焦分隔线后，用左右方向键调整；Home／End 分别设为最小／最大宽度。
- 宽窗口中，侧栏顶部是图标标签页。选中的标签页显示名称，其他只显示图标，悬停可见提示。左右方向键、Home／End 在标签页之间移动。点击边缘按钮关闭或打开整个侧栏。
- Bot 私聊有 **会话**（会话与 Bot 收件箱）和 **记忆**（记忆文件与记忆演化）；其他项目（包括可选插件的项目）各占一个标签页。Bot 收件箱只在有记录时出现。
- 有两个可见项目的标签页分为上下两个区域，各自滚动。拖动中间的分隔条，或聚焦后按上下方向键（按住 Shift 步长更大）、Home／End 调整；双击恢复为各占一半。比例按标签页记住。
- 窄窗口（960 px 及以下）中以覆盖面板打开，显示可折叠的项目：点击项目标题展开或收起。使用按钮、背景遮罩或 Escape 关闭；切换聊天也会关闭临时面板。

## 排序与显示

宽窗口中，点击标签页旁的 **+ 视图**：

1. 取消或勾选标签页的复选框，隐藏或显示它。至少保留一个视图。
2. 拖动手柄改变顺序；也可聚焦该行后按 Alt + 上下方向键。
3. 修改立即生效。按 Escape 或点击菜单外关闭。

窄窗口的覆盖面板中，改为从齿轮菜单选择 **编辑侧边栏**：

1. 拖动项目手柄改变顺序；也可聚焦手柄后按上下方向键。
2. 点击 **隐藏 …** 或 **显示 …**，选择要显示的项目。
3. 点击 **完成** 保存草稿，点击 **取消** 放弃修改。
4. **恢复默认布局** 只先重置草稿中的默认顺序与显示状态；仍须点击 **完成** 才会应用。

![窄窗口覆盖面板编辑模式中的排序与显示控件](/guides/channel-sidebar/08-sidebar-display-zh.webp)

隐藏的标签页和项目会保留其数据。Bot 与 Channel 分别保存排序和隐藏偏好；切换 Bot 不会生成一份新的 Bot 专属顺序。选中的标签页和各项目的展开或收起状态按选中的 Bot 或 Channel 记住。偏好存储在当前客户端浏览器，本教程不承诺其他浏览器或设备自动共享它们。

## 各功能的显示选项

| 齿轮菜单项目        | 选项与作用                                 |
| ------------------- | ------------------------------------------ |
| 记忆演化 · 显示术语 | **记忆** 或 **Git** 标签与分组，不改仓库。 |
| 会话 · 会话范围     | 当前 Bot 所属会话的 **当前** 或 **全部**。 |
| 会话 · 排列方式     | **平铺** 或 **按工作区**，不移动 Session。 |

这些菜单选项立即生效。窄窗口覆盖面板中，它们与 **编辑侧边栏** 草稿里的 **完成／取消** 分开；打开某个功能的设置子菜单时，可以临时预览该项目，菜单关闭后恢复原来的展开状态。

具体含义见[记忆演化](/zh/docs/channel-sidebar/memory-evolution)和[会话](/zh/docs/channel-sidebar/sessions)。可选插件可在可用时增加自己的显示选项。[返回侧栏总览](/zh/docs/channel-sidebar)。
