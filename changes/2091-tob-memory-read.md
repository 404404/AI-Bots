## en

- Tob can delegate selected Bots' Memory comparisons to its own Assignment Session through a revocable read-only CLI scope, returning source Bot/file/revision and bounded partial/unavailable results through the existing report path ([#2091](https://github.com/BotHarness/DeepSeekBot/issues/2091), [CLI guide](../docs/bot-cli.md#tob-assignment-memory-reading)).

## zh

- Tob 可通过可撤销的只读 CLI 范围，把选定 Bot 的 Memory 比较交给自己所有的 Assignment Session，并沿正常报告路径返回来源 Bot/文件/修订及有界 partial/unavailable 结果（[#2091](https://github.com/BotHarness/DeepSeekBot/issues/2091)、[CLI 指南](../docs/bot-cli.md#tob-assignment-memory-reading)）。
