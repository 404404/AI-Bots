## en

- Web chat bubbles now follow the mobile design: the Bot's bubble is a flat, solid surface with no edge, and in a DM the Human's bubble takes that Bot's primary colour (Channels use the accent), with text that always reaches 4.5:1. Text bubbles are more compact, option lists inside cards drop their outline and show a chosen row as an accent tint, and the tool approval and question cards use solid pill buttons with a neutral primary and a readable red Reject on a solid tint ([#1643](https://github.com/BotHarness/DeepSeekBot/issues/1643)).

## zh

- Web 端聊天气泡改用手机端的设计：Bot 气泡改为无描边的纯色底；私聊中用户气泡的底色改为该 Bot 的主色（频道中使用强调色），文字对比度始终不低于 4.5:1。纯文字气泡更紧凑，卡片内的选项列表去掉外框，选中项改用强调色浅底；工具审批和提问卡片改用实心胶囊按钮，主按钮为中性色，拒绝按钮为实色浅红底上的可读红字（[#1643](https://github.com/BotHarness/DeepSeekBot/issues/1643)）。
