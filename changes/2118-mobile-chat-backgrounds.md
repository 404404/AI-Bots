## en

- Mobile chats can preview and save a device-local photo or solid background, with Fill/Fit, image position and background fade. Set a default in Settings or customize a DM/group; cancel and failed saves retain the saved choice ([#2118](https://github.com/BotHarness/DeepSeekBot/issues/2118)).

## zh

- 移动端聊天可预览并保存仅在本机使用的照片或纯色背景，支持填充/适应、图片位置与背景淡化。可在设置中选择默认背景，或单独设置私信和群聊；取消和保存失败时保留原选择（[#2118](https://github.com/BotHarness/DeepSeekBot/issues/2118)）。
