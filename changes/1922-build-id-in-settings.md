## en

- Settings now shows a build id — the short git SHA and build time — in the Web Client (Settings → About → Build) and in the DeepSeekBot mobile app (Settings → About → Build), so you can tell which build is installed ([#1922](https://github.com/BotHarness/DeepSeekBot/pull/1922)).
