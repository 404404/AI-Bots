## en

- A Bot question with more than three items or a long description now appears as a card in the Channel and the Window Companion, instead of only in DSH's own question view, so you no longer leave Bot mode to answer it ([#1641](https://github.com/BotHarness/DeepSeekBot/pull/1641)).

## zh
