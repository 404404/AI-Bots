## en

- The first time you enter Bot mode, a five-step intro greets you as Tob, lets you pick a color mode, theme color, wallpaper and default model (with an Advanced option for a separate task model), shows the community links with user reviews and a note from the founder, and starts your first chat with Tob. The desktop companion now drops in from the top when Bot mode opens and stays hidden while the intro is open. Anonymous usage statistics now include which intro steps were seen, skipped or completed and tutorial actions, without any typed text or model names ([#2361](https://github.com/BotHarness/DeepSeekBot/pull/2361)).

## zh
