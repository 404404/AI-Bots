## en

- Wide Bot mode workspaces on qualified Web and macOS shells now have a movable full-height control rail, an independent Channel list and closable Messages with a group-member split, reorderable switches, customizable shortcuts and continuous spacing (4px by default) between subtly contrasting rounded panels, configured in Bot Settings, consolidated Channel header actions and pointer-aligned DM menus with profile access, centered panel-icon empty states and consistent 2px content insets, with proportional layout restoration and live content retained during dragging and native sidebar recovery on exit ([#2017](https://github.com/BotHarness/DeepSeekBot/issues/2017)).

## zh

- 符合条件的 Web 与 macOS 宽屏 Bot 模式新增可移动的全高控制列、独立 Channel 列表和可关闭的消息面板及内部分割的群成员、可排序开关、自定义快捷键，以及低对比小圆角面板间的连续可调间距（默认 4px，统一在 Bot 设置调整）；频道操作合入标题栏，右键菜单贴合光标并提供「查看资料」，面板统一通过控制列开闭；空状态以面板图标和说明居中呈现，面板内容四边统一保留 2px；支持按比例恢复布局、拖拽保留内容，并在退出时恢复原生侧栏（[#2017](https://github.com/BotHarness/DeepSeekBot/issues/2017)）。
