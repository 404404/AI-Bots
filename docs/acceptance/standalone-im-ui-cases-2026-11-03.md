# Standalone IM 界面验收用例（2026-11-03）

在隔离数据目录和独立端口执行，不访问或迁移现有 20443、22443、23443 数据。记录源码、测试环境、实际浏览器和每项证据；模拟结果与真实页面结果分列。

1. 将真实私聊与群聊聚合到一个会话栏，按实际活动排序；主 Bot 与其他 Bot 样式一致，仅显示星号，不自动置顶。
2. 会话置顶和取消置顶由服务端持久化，刷新和重启恢复；未读按服务端游标计算，打开会话后清除，跨会话隔离。
3. 私聊发送、模型选择、Codex Auth、群聊发送、成员选择、历史分页及恢复沿用真实业务实现；主 Bot 委派继续使用任务权威。
4. Bot 和群的详情面板可打开、关闭，正确显示其真实信息；不存在的文件、记忆或任务能力须明确标注，不能生成示例数据。
5. Bot 间通信摘要仅引用已持久化的真实事件，按方向显示来源或目标；点击显示真实参与者、消息、时间和附件（如存在），键盘可进入和关闭，长内容可滚动。普通通信不标为任务；缺少真实通信或附件时显示空状态，不伪造内容。
6. 在 1920、1366、768、390 CSS 像素宽度检查会话栏、聊天、详情和弹窗的可见性、可操作性与溢出；截图分别保存正常聊天和真实 Bot 间通信详情。
7. 测试服务端跨 Bot/群权限、通信来源和游标边界；迁移使用独立数据库，版本、备份与失败处理可追溯。
8. 执行完整 standalone 测试、构建及受影响模块测试；记录失败、未覆盖项和运行命令，不删除断言。
9. 检查受保护容器镜像、状态与端口；不修改 Browser Worker 安全门禁及现有实例数据。测试数据和清理结果如实记录。
