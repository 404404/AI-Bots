## en

- In the DeepSeekBot mobile app, Bot messages and streaming replies are now drawn as native text with GitHub-flavoured Markdown, so tables show as real tables, and a long reply costs the phone far less work on each streamed update ([#1838](https://github.com/BotHarness/DeepSeekBot/issues/1838), [#1804](https://github.com/BotHarness/DeepSeekBot/issues/1804)).

## zh

- DeepSeekBot 手机 App 里，Bot 的消息和流式回复现在用原生文本渲染 GitHub 风格的 Markdown：表格会显示成真正的表格，长回复在每次流式更新时手机要做的工作也少得多（[#1838](https://github.com/BotHarness/DeepSeekBot/issues/1838)、[#1804](https://github.com/BotHarness/DeepSeekBot/issues/1804)）。
