## en

- Settings → About in the Web Client and in the DeepSeekBot mobile app shows a build id: the short git commit and the local build time (the mobile app also shows its version and branch), so a test build can be told apart at a glance; tapping the mobile row copies it ([#1923](https://github.com/BotHarness/DeepSeekBot/pull/1923)).

## zh

- Web Client 和 DeepSeekBot 手机 App 的「设置 → 关于」会显示构建号：git 短提交号和本地构建时间（手机 App 还显示版本号和分支），测试时一眼就能分辨装的是哪个包；手机上点一下即可复制（[#1923](https://github.com/BotHarness/DeepSeekBot/pull/1923)）。
