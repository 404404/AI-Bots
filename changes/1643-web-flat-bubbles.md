## en

- Web chat bubbles now follow the mobile design: the Bot's bubble is a flat, solid surface with no edge, and in a DM the Human's bubble takes that Bot's primary colour (Channels use the accent), with text that always reaches 4.5:1. Text bubbles are more compact, and option lists inside cards drop their outline and show a chosen row as an accent tint ([#1643](https://github.com/BotHarness/DeepSeekBot/issues/1643)).

## zh

- Web 端聊天气泡改用手机端的设计：Bot 气泡改为无描边的纯色底；私聊中用户气泡的底色改为该 Bot 的主色（频道中使用强调色），文字对比度始终不低于 4.5:1。纯文字气泡更紧凑，卡片内的选项列表去掉外框，选中项改用强调色浅底（[#1643](https://github.com/BotHarness/DeepSeekBot/issues/1643)）。
