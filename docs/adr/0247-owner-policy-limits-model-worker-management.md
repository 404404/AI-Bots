# ADR-0247：所有者策略限定模型创建和配置工作 Bot

状态：Accepted（下一切片目标设计，尚未实现或验收）

日期：2026-10-30

范围：用户 fork 的 `standalone/` 独立产品。

## 背景

单工作 Bot 委派切片使用所有者事先创建的目标和明确连接引用。用户要求主 Bot 在对话中创建、配置并调用工作 Bot。模型生成工具参数不能因此变成凭据或权限管理入口。

## 决策

1. 所有者在网页或同业务 CLI/API 中明确启用协调策略，决定是否允许创建、配置哪些已授权工作 Bot，以及可供新工作 Bot 使用的模型连接引用。默认不启用创建。名称、persona 和模型自称身份不影响策略。
2. 创建工具只接受操作 ID、名称、persona 和策略内的连接引用 ID；不接受任意 source Bot ID、凭据、主身份、权限、模型配置或记忆。服务端核验引用当前仍授予主 Bot 且源 epoch 有效，在同一事务中新建稳定 UUID、消费者引用及委派授权。秘密仍只属于源 Bot。
3. 更新工具只接受策略内工作 Bot 的稳定 ID、名称和 persona；主 Bot、连接源配置、凭据、权限、删除和记忆写入不在其能力范围。名称相同不改变对象选择。Bot 管理和模型工具使用同一管理业务模块及字段校验。
4. 根执行记录提交时的策略 revision 和允许连接/目标快照。模型工具还需检查当前策略；撤销或版本变化导致明确拒绝，不扩大旧执行的范围。本次按策略创建的工作 Bot 可以由服务端将其确切 UUID 加入当前执行范围，不能由模型声明任意目标。
5. 创建和更新以操作 ID、规范化参数摘要和持久回执保证幂等，事务覆盖对象及引用写入。模型使用真实工具调用 ID；直接调用使用显式操作 ID。已执行结果重复读取，不重复创建或修改。工具和子任务有根级总预算，不因进入下一模型轮次而重置。
6. 本阶段默认每根最多创建 2 个工作 Bot、创建 3 个工作任务、执行 8 次工具调用、最多 12 次模型轮次；全局根执行上限 4、工作执行上限 2，深度仍为 1。工具预算计入无效、未知或被拒绝的尝试，拒绝回执重放不重做副作用。所有者界面展示硬预算；实现如需降低预算须同步合同与用例。超过容量直接拒绝受理，没有持久队列；父协调模型不占工作执行槽。主根任务从受理起最多 300 秒，工作任务最多 90 秒且不超过根截止时间，等待与所有模型轮次共用同一绝对截止时间，不因下一轮或重试延期。
7. 每个子任务在受理时固定名称、persona、配置 revision、模型授权版本和实际读取的记忆 revision。修改后的行为只影响后续执行。工作 Bot 不继承主对话历史、其他 Bot 记忆或凭据；工具结果始终标为不可信数据。

## 验收

按 DG-03 验证真实 LAN 对话创建、配置、按稳定 ID 委派、真实工作模型结果及主模型汇总；工具回执、配置快照和实际页面状态需对应。模拟只验证协议与业务。覆盖同名/重命名、重试/冲突、撤销/epoch 变化、越权字段、主身份保护、多工作任务、预算与取消/重启。未取得真实链证据前不宣布完成或发布。
