## en

- In the DeepSeekBot mobile app, the Activity tab now lists each pending Human question and Tool approval as a post with its card, so you answer or allow it in place and the post leaves the feed once the Host accepts it. Question options sit in one joined group like the Web Client's Ask Question card, in the DM and the Inbox alike ([#1653](https://github.com/BotHarness/DeepSeekBot/issues/1653)).
- A chosen option in a Human question card no longer has an accent bar on its left edge, in the Web Client and the mobile app; a row tinted with the accent marks it, as in the Web Client ([#1653](https://github.com/BotHarness/DeepSeekBot/issues/1653)).
- Web Client Human question cards now letter their options A, B, C like the mobile app, and the chosen option's letter fills with the accent colour ([#1653](https://github.com/BotHarness/DeepSeekBot/issues/1653)).

## zh

- DeepSeekBot 手机 App 的「活动」页现在把每个待回答的问题和待审批的工具调用列成一条带卡片的动态，可以直接在原地回答或批准；Host 接受后，这条动态会从列表中消失。问题的选项像网页版的提问卡片一样连成一组，私聊和 Inbox 里都是这样（[#1653](https://github.com/BotHarness/DeepSeekBot/issues/1653)）。
- 问题卡片里选中的选项不再在左侧显示强调色竖条，网页版和手机 App 都是如此；改用和网页版一样的淡强调色底色标出选中的选项（[#1653](https://github.com/BotHarness/DeepSeekBot/issues/1653)）。
- 网页版的问题卡片现在也像手机 App 一样用 A、B、C 标出选项，选中的选项字母会填上强调色（[#1653](https://github.com/BotHarness/DeepSeekBot/issues/1653)）。
