## en

- DeepSeekBot can save an image wallpaper on the current Web or Desktop device, preview its crop, and show one continuous background behind the sidebar and panels. Decode or storage failure preserves the previous image; the targeted CLI can import, crop and remove it without a Host media copy ([#2262](https://github.com/BotHarness/DeepSeekBot/issues/2262)).

## zh

- DeepSeekBot 支持在当前 Web 或桌面设备保存图片壁纸、预览裁切，并在侧边栏和面板背后显示连续背景。解码或保存失败会保留原图片；定向 CLI 可导入、裁切及移除，Host 不保存媒体副本（[#2262](https://github.com/BotHarness/DeepSeekBot/issues/2262)）。
