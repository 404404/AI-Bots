## en

- The mobile app answers a Bot's folder request directly: choose a folder on your computer and allow read/write, and the original task continues without opening the desktop app. Folder requests now send a phone notification under Approvals ([#2080](https://github.com/BotHarness/DeepSeekBot/issues/2080)).

- Mobile tool approvals now offer the same Allow once, Always allow and Reject as the Web card. Always allow remembers the tool for this Bot in the current scope, stays unavailable with a reason when only a one-time Human decision is allowed, and notifications only offer it when the computer does ([#2080](https://github.com/BotHarness/DeepSeekBot/issues/2080)).

## zh

- 手机可以直接处理 Bot 的文件夹请求：选择电脑上的文件夹并允许读写后，原任务会继续，无需打开桌面端；文件夹请求现在也会按“审批”类别推送到手机（[#2080](https://github.com/BotHarness/DeepSeekBot/issues/2080)）。

- 手机上的工具审批与网页一致，提供“允许这次／始终允许／拒绝”。“始终允许”会记住此 Bot 在当前范围使用这个工具；只能由 Human 单次决定的请求会置灰并说明原因，通知也只在电脑允许时提供“始终允许”（[#2080](https://github.com/BotHarness/DeepSeekBot/issues/2080)）。
