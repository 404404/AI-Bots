# ADR-0245：独立任务使用执行作用域和模型连接引用

状态：Accepted（用户 fork 的目标设计；尚未据此声明实现）

日期：2026-10-29
范围：`standalone/`，不适用于旧 DSH Host。

## 问题

主 Bot 必须通过真实模型工具委派工作，而模型生成的参数、角色提示和工作结果均不构成授权。现有每 Bot 登录不能通过复制 OAuth 变成隐式共享。任务必须在异常、重试和重启时留下准确的持久状态。

## 决策

### 一项任务，一个受限执行作用域

独立 SQLite 是 task、父子关系、执行状态、结果和工具轨迹的唯一事实来源。任务拥有稳定 UUID、根任务/父任务 ID、发起者和执行者 ID、幂等键及输入摘要、输入、配置版本、状态、结果/错误、起止时间和截止时间。通知只提示重新读取这些事实。

所有者通过网页或 CLI 创建根任务。模型工具使用服务器构造的作用域：执行者、当前任务、允许工具、可委派目标和剩余深度。模型参数中相同名称的字段不参与授权。子任务只收到明确任务输入及执行者自己的身份与已保存文件记忆；不自动复制父对话、父记忆、其他 Bot 历史或凭据。

首个委派闭环只允许主 Bot 调用一个工作 Bot；工作 Bot 无委派权限。后续多个工作 Bot 仍受相同根任务预算约束。祖先执行者不得再次作为目标；深度、总任务数、工具次数、同时活动数及墙钟时间均设硬上限。首片无可用槽时明确拒绝受理，不生成虚假排队状态；根模型与工作任务分别有界，避免父任务占满工作槽而死锁。若后续引入排队，必须持久记录入队及恢复策略，再按独立用例验收。

### 主 Bot 的工具权限由所有者配置

所有者明确启用协调，并授权允许调用的工作 Bot、可用模型连接及是否允许创建工作 Bot。主 Bot 可以读取无秘密目录；名称/角色配置工具只能修改获授权工作对象的行为配置，不能改变授权、主身份、凭据或跨对象记忆。新建工作 Bot 的连接引用只能取自所有者已授予的范围。模型、页面或子结果不能扩大这些范围。

工具调用必须来自模型协议中真实的 tool call，记录工具名、调用 ID、任务和来源；普通回复中的 JSON/标记不执行。直接 CLI/API 与模型工具调用进入同一任务和管理业务模块，区别仅在可信调用上下文及其权限范围。

### 模型连接通过服务端引用共享

所有者可创建指向既有独立产品模型连接的引用，并授权指定消费者。引用保存来源、消费者、配置版本和撤销状态；不复制源 Bot 的 OAuth、刷新令牌或 API Key。模型只能获得连接 ID/可用性，秘密仅由服务端连接解析器读取。源配置变更、删除或撤销应导致明确的拒绝或要求重新授权，不能悄然改用其他连接或直连。

本设计不引用旧 DSH 授权。未获连接授权的主 Bot 保持明确的“需要配置连接”状态。

### 幂等、取消和恢复

根请求幂等键限定所有者和操作，工具请求限定父任务和真实工具调用 ID；相同键不同规范化输入返回冲突。保存任务和接受状态在同一事务中完成。子任务结果可重复读取，但不能重复执行。

取消先持久化，再传播到活动子任务与模型/浏览器 AbortSignal。完成写入以活动状态为条件，迟到结果不能覆盖取消、失败或中断。截止时间覆盖等待和执行，不因重试延长。

重启后保留 completed/failed/cancelled；已开始而未终结的任务标为 interrupted。尚未开始的任务须有明确恢复策略和可见状态，不能盲目重发可能产生副作用的动作。首次实现选择中断所有未终结任务并由所有者以新的操作明确重试，保留原任务关联。

### 结果来源与不可信内容

网页显示主/工作 Bot 的稳定 ID、task ID、父子链、状态、结果和错误；汇总回复引用真实完成的子任务。任务结果和浏览器页面均为不可信数据，作为带来源的工具结果进入模型，不进入系统指令。任何记忆写入仍限所有者明确保存，并使用 revision；本阶段不提供模型自动记忆写入工具。

## 交付顺序与验证

在主身份首片通过后，先完成一工作 Bot 的真实模型工具委派与汇总，再补充并发、故障和取消矩阵。直接任务 API 测试、模拟协议测试、真实 Codex 工具链和 LAN 页面是分别记录的证据。未取得真实主→子→主回复，不能将任务列表或工具模拟计为真实委派通过。

所有 schema 变更必须使用版本迁移，在合成/隔离数据测试失败停止与备份恢复。发布镜像、迁移后的数据和迁移前备份分别记录身份与回退边界。
