## en

- **Settings → Data & privacy → Storage** shows how much space chat media, messages and Memory use, and lists each chat's media. Pick an age, media types and chats, review what is deleted and how much space is freed, then clear. Text messages stay, and each cleared file shows as a `Cleared` card in its message. Media a Bot is still working on, media still being sent and media Memory uses are kept. The `deepseekbot storage-usage`, `storage-cleanup-preview` and `storage-cleanup-confirm` commands do the same ([#2430](https://github.com/BotHarness/DeepSeekBot/issues/2430)).

## zh

- **设置 → 数据与隐私 → 存储空间**会显示聊天图片和文件、聊天记录、记忆各占多少空间，并列出每个聊天的媒体大小。选好时间、类型和聊天后，先预览会删除什么、能释放多少空间，再确认清理。文字消息会保留，清理掉的文件在消息里显示为“已清理”。Bot 还在处理、还在发送或被记忆引用的媒体会保留。也可以用 `deepseekbot storage-usage`、`storage-cleanup-preview` 和 `storage-cleanup-confirm` 命令完成同样的操作（[#2430](https://github.com/BotHarness/DeepSeekBot/issues/2430)）。
