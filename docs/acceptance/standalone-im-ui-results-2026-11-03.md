### 部分验证和未覆盖

- 浏览器覆盖普通私聊和合成通信浮窗；手动置顶排序、未读、群成员、历史恢复、详情面板、键盘关闭和长内容滚动尚未完成全套真实浏览器验证。浮窗未在四种视口逐一验证。
- 真实外部 Codex 模型驱动的 Bot 间通信尚未验证；截图不能代替该验收。兼容模型的发起端尚无 `send_bot_message` 工具循环。
- 全局 provider 改变后，Bot 已保存的旧模型选择不会自动改写；若不再可用，接收通信可能返回 `model-not-authorized`，需在对应 Bot 显式选择可用模型。
- 390 宽度截图中较早欢迎语因滚动被裁切，但目标问答与输入控件可见。截图仍显示欢迎语的角色分析进行中，不能证明该状态已同步完成。
- 工作区/用户角色切换、群文件、群记忆、附件等没有相应可用后端时仍为不可用或未提供状态；不以示例数据冒充。截图浮窗仅展示已有消息，不提供附件下载。
- 原仓库根项目全量测试及构建另行记录；它们不能由 standalone 的结果推断。

### 与参考图的差异

参考图的头像、群组详情卡片、操作栏与文件附件样式尚未完全实现；当前采用简化配色、紧凑对话卡片和原生弹窗。单一会话栏、按需发起私聊和可关闭详情已实现，但全量视觉和交互验收仍有上述缺口。

## Bot 间消息归属

旧版本没有普通 Bot 间消息持久历史。新增独立 SQLite schema 12 保存授权配对、消息和接收执行状态；任务仍由原任务表管理，不将任务伪装成普通通信。发送者由运行中的工具执行身份派生；来源会话及 Run 从实际任务关系记录，回复通过消息 ID 关联。UI 只将精确来源会话的记录投影到聊天流。已授权的 Bot 对共享自己的消息线程，接收方可看到该线程的先前消息，即使其来自不同来源私聊；这不代表可以读取那些私聊正文。普通消息附件当前没有持久化能力。
