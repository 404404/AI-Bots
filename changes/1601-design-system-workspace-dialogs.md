## en

- Larger dialogs now share the same layout as forms: one title, consistent spacing and type, and their actions in a single footer row with any side action on the left. This covers the model editor, the workspace folder browser, avatar and primary colour, IM pairing, approval and permission groups, behaviour permissions, role and exception editors, the Bot Marketplace, profile backup, memory backups, the assignment limit, external source details, IM authorization, group workspace grants, the DM composer's model and workspace panels, hidden channels and group invitations. Role, permission-exception and group-deletion dialogs submit with Enter, and deleting a permission group uses a red button. Dialogs now come in three widths: 440, 760 and 1060 pixels ([#1601](https://github.com/BotHarness/DeepSeekBot/issues/1601)).

## zh

- 较大的对话框和表单统一成同一种布局：一个标题，间距与字号一致，操作按钮集中在底部一行，次要操作放在左侧。覆盖模型编辑、工作区文件夹浏览、头像与主色、IM 配对、审批与权限组、行为权限、角色与例外编辑、Bot 市场、资料备份、记忆备份、并行任务上限、外部来源详情、IM 授权、群工作区授权、私聊输入框里的模型与工作区面板、隐藏频道以及群邀请。角色、权限例外和删除权限组的对话框按回车即可提交，删除权限组使用红色按钮。对话框宽度统一为 440、760、1060 像素三档（[#1601](https://github.com/BotHarness/DeepSeekBot/issues/1601)）。
