## en

- Mobile Settings can configure the Host's global default model and shared Model Presets; each Bot can configure its Orchestrator, Assignment default, allowed models and reasoning effort, apply or save a preset, or return to the global default. Model pickers search model and provider names ([#2086](https://github.com/BotHarness/DeepSeekBot/issues/2086)).

## zh

- 移动端设置支持修改 Host 的全局默认模型及共享模型预设；每个 Bot 可配置 Orchestrator、Assignment 默认与可选模型、推理强度，应用或保存预设，并恢复全局默认。模型选择支持搜索模型与服务商名称（[#2086](https://github.com/BotHarness/DeepSeekBot/issues/2086)）。
