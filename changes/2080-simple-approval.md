## en

- Simplified ordinary Web tool approvals to Allow once, Always allow and Reject; Always allow remembers only the selected tool in the current authority scope. Full Access automatically handles ordinary requests while permission changes can still reach a Human through native approval; existing rules and selected access scopes retain their meaning ([#2080](https://github.com/BotHarness/DeepSeekBot/issues/2080)).

## zh

- 普通网页工具审批统一为“允许这次／始终允许／拒绝”；始终允许只记住当前授权范围中的当前工具。Full Access 自动处理普通请求，权限变更仍可通过原生审批到达 Human；旧规则和已选访问范围保持原义（[#2080](https://github.com/BotHarness/DeepSeekBot/issues/2080)）。
