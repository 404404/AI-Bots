# 单用户员工与群聊验收用例（2026-10-31）

主代理先写；GPT 6 Luna 实现；GPT 6.1 Terra 独立执行。依据 [ADR-0250](../adr/0250-single-user-model-account-and-employee-conversations.md)。以下是验收标准，不表示已经实现或通过。

| ID | 场景 | 通过条件 |
| --- | --- | --- |
| SU-01 | 一次设置 Codex 登录，在多个现有/新员工打开私聊 | 每个员工可选择并调用同一用户来源的可用模型；只一份服务端授权，不复制到员工；网页、CLI/API 状态一致。 |
| SU-02 | 旧 schema8：无授权、唯一授权、多个冲突授权及异常回滚 | 唯一来源事务安全采用；冲突不静默覆盖或丢弃；失败可恢复，旧 Bot/消息/记忆/任务/授权与 ID 保留。只能在独立数据副本测试。 |
| SU-03 | 登出、更新账号/模型、在途请求及代理失败 | 所有员工一致失效或更新；迟到结果不越权发布；错误码明确、无隐式直连，凭据不进入响应/日志/模型上下文或仓库。 |
| SU-04 | 空数据、1 员工、2+ 员工，升级既有多员工 | 零时引导创建；唯一员工自动作为主要联系人；多个时要求用户选择，可更改并重启恢复，历史自动 singleton 不冒充用户选择。 |
| SU-05 | 名称重复/改名、伪造主要联系人角色、API actor | 主要联系人和委派按稳定 ID；名称、角色、聊天文本不能授予身份、创建员工、修改设置或提高权限。 |
| SU-06 | 用户创建新员工，模型有/无授权、失败或重启 | 用户提供名称和定义；首条询问自动保存在该员工私聊且恰一次；模型不可用时预设欢迎语明确标识，角色分析明确待完成/可重试；真实名称分析须有模型证据，不静默伪造。 |
| SU-07 | 主动请求委派与协调者自行分析委派 | 不需要设置逐 Bot 授权；真实调用现有员工、持久任务和结果汇总，时间线与详情可见；不存在目标时明确失败。 |
| SU-08 | 模型尝试创建或修改员工、旧策略开关启用、恶意任务输出 | 模型无此工具/能力，服务端统一拒绝绕过；用户仍可通过网页及认证 CLI/API 创建和修改自己的员工。 |
| SU-09 | 同键重试、并发、循环/深度、失败、取消、重启 | 单次执行，限制有界；终态和父子来源可追溯；中断动作不自动重发，跨员工私聊/记忆隔离。 |
| GR-01 | 创建含两个已存在员工的群，刷新和重启 | 群 ID、名称、成员、默认回复员工与历史真实持久；无需另行复制授权，CLI/API 与网页使用同一数据。 |
| GR-02 | 用户在真实网页 @ 或选择一个群成员并发送 | 指定员工真实模型回复，同一群按时间显示真实姓名、头像、稳定 sender ID；输入区模型与实际请求一致。 |
| GR-03 | 同一群选择两个员工依次回应 | 两个真实执行及结果落在同一群并正确归属；第二个员工仅收到允许的同群上下文，不继承其他员工私聊或记忆。 |
| GR-04 | 未指定成员、重复名称、成员移除/迟到回复 | 仅明确默认成员或要求用户选择；使用稳定 ID；移除后拒绝新执行和迟到发表，不能冒认成员。 |
| GR-05 | 多群、私聊、角色/页面恶意指令和凭据 | 不同群及私聊互相隔离；群消息/模型文字不启动未授权工具或无限互唤，不泄露秘密。 |
| GR-06 | 群发送幂等、并发、取消、失败、超时、断线与重启 | 持久真实状态、明确错误和来源，无重复发送或盲目副作用重放；刷新/重启可见。 |
| SU-10 | 新 schema 备份、失败停止、代码及数据回退 | 使用独立副本验证；旧镜像拒绝新 schema，旧备份可恢复；切回旧数据会失去备份后写入，分别记录。 |
| SU-11 | 固定 CI 产物、隔离端口、真实 LAN 页面与对照服务 | 测源/镜像/digest 一致；旧 GUI 停止、22443 及其他服务不受影响。模拟模型、API、真实模型和真实页面证据不可互相替代。 |

结果分为通过、失败、部分验证、外部条件阻塞和未实现。测试使用独立数据、隔离测试页面和合成任务；不得输出、截图或提交访问码、cookie、API Key、OAuth 凭据。真实模型必须有真实回复，实际远端 EasyTier 设备未测不得写成通过。
