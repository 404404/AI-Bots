## en

- **Storage** on the web and in the phone app can now delete whole old messages: choose **Clear → Whole messages**, an age and chats, review how many messages and files go, then delete. Each message stays in place as a deleted message and keeps its delivery status, messages a Bot is still working on are kept, and Bot Memory is not changed. The `deepseekbot storage-messages-cleanup-preview` and `storage-messages-cleanup-confirm` commands do the same ([#2430](https://github.com/BotHarness/DeepSeekBot/issues/2430)).

## zh

- 网页和手机 App 的**存储空间**现在可以删除旧的整条消息：选择**清理内容 → 整条消息**、时间和聊天，确认会删除多少条消息和文件后再删除。每条消息会在原位置显示为“已删除”，送达状态保持不变，Bot 还在处理的消息会保留，Bot 的记忆不受影响。也可以用 `deepseekbot storage-messages-cleanup-preview` 和 `storage-messages-cleanup-confirm` 命令完成同样的操作（[#2430](https://github.com/BotHarness/DeepSeekBot/issues/2430)）。
