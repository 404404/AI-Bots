## en

- Customize the desktop Web composer footer from its context menu: show or hide model, workspace, token usage and generation speed; drag items within the footer to reorder or align left/right, with an insertion indicator and keyboard alternatives. The footer stays on one line and truncates long names. Preferences stay in this browser; restore defaults at any time. Model, workspace and token usage are visible by default; generation speed and per-reply speed labels are opt-in. Completed replies use provider token counts when usable, otherwise a labeled text estimate. The optional conversation average reads at most 200 messages over four pages and refreshes for completed measured replies, with no polling or history reads while hidden. Phone-width Web retains its compact footer ([#1958](https://github.com/BotHarness/DeepSeekBot/issues/1958)).

## zh

- 桌面 Web 输入框底部支持右键自定义：显示或隐藏模型、工作区、Token 用量和生成速度；进入调整模式后可拖动排序、靠左或靠右放置，并显示插入线，也支持键盘操作。底部保持单行，长名称显示省略号。设置只保存在当前浏览器，可随时恢复默认。默认显示模型、工作区和 Token 用量；生成速度及逐条回复速度需手动开启。已完成回复优先使用可用的 Provider Token 计数，否则标注为文本估算。可选平均速度最多读取四页、200 条消息，只在新的已测量回复完成时刷新，隐藏时不读取历史，也不轮询。手机宽度的 Web 保留精简底部栏（[#1958](https://github.com/BotHarness/DeepSeekBot/issues/1958)）。
