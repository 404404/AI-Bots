## en

- Tob can create a Bot with initial personality and Memory, reconcile a lost response without duplicating its identity, and manage reviewed profile and lifecycle changes through the CLI. Deletion retains Memory unless explicitly selected for erasure; CLI deletion confirmation and retry now require `--confirm` ([#2089](https://github.com/BotHarness/DeepSeekBot/issues/2089), [CLI guide](../docs/bot-cli.md#tob-bot-creation-profiles-and-lifecycle)).

## zh

- Tob 可通过 CLI 创建带初始人格与记忆的 Bot，在响应丢失后核对原身份避免重复创建，并经审核管理资料和生命周期。删除默认保留 Memory，擦除需显式选择；CLI 删除确认与重试现在必须传 `--confirm`（[#2089](https://github.com/BotHarness/DeepSeekBot/issues/2089)、[CLI 指南](../docs/bot-cli.md#tob-bot-creation-profiles-and-lifecycle)）。
