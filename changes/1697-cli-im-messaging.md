## en

- You can now manage a Bot's IM messaging from the CLI against a live Host: read and set messaging defaults, group and thread policies and sender access; list reachable targets and conversations; authorize, revoke, send and post proactively with a post limit; inspect Channel bridges; and route, test and retry approvals and failure alerts, through the same checks as the Web UI (`deepseekbot messaging-*`, `sender-access`, `channel-bridge(s)`, `approval-*`, `failure-alerts-*`) ([#1697](https://github.com/BotHarness/DeepSeekBot/issues/1697)).

## zh

- 现在可以用命令行对在线 Host 管理 Bot 的 IM 消息：读取和设置消息默认值、群聊与话题策略和发送者权限；列出可触达的目标和会话；授权、撤销、发送消息，以及在发帖上限内主动发帖；查看 Channel 桥接；配置、测试和重试审批与失败提醒，检查与 Web UI 相同（`deepseekbot messaging-*`、`sender-access`、`channel-bridge(s)`、`approval-*`、`failure-alerts-*`）（[#1697](https://github.com/BotHarness/DeepSeekBot/issues/1697)）。
