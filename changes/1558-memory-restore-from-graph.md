## en

- Memory evolution can restore Memory to any Git graph commit from inside that commit's block, after automatically backing up the current state including uncommitted files; the restore adds a new commit, the Memory file list refreshes right away, and the recovery list is now called Automatic backups ([#1558](https://github.com/BotHarness/DeepSeekBot/pull/1558)).

## zh

- 记忆演化可以在 Git 图的任意提交方块里「恢复到这次提交」：先自动备份当前状态（含未提交文件），再以新提交恢复所选记忆，记忆文件列表随即刷新；原恢复检查点列表改名为「自动备份」（[#1558](https://github.com/BotHarness/DeepSeekBot/pull/1558)）。
