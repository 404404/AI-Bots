## en

- Mobile: chat rows in Chats and **Send to** now show the computer's chosen icon and colour after the chat name, in place of the generic computer mark, so chats from different places are easy to tell apart in **All**. Cloud chats keep the cloud mark ([#2499](https://github.com/BotHarness/DeepSeekBot/pull/2499)).

## zh

- 移动端：「聊天」和「发送到」里的会话行，名字后面改为显示该电脑自定义的图标和颜色，不再是通用的电脑图标，在「全部」里更容易分清会话来自哪里。云端会话仍显示云图标（[#2499](https://github.com/BotHarness/DeepSeekBot/pull/2499)）。
