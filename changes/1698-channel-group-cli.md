## en

- Agents can now manage Channels and groups from the `deepseekbot` CLI against a running Host: rename a Channel, set a group avatar, invite Bots or cancel invitations, decide join requests, remove members, read and set wake policies, page the timeline and journal, mark Channels read, retry a failed DM reply, review history, and preview and confirm a purge or delete a group with `--confirm` ([#1698](https://github.com/BotHarness/DeepSeekBot/issues/1698)).

## zh

- Agent 现在可以用 `deepseekbot` 命令行对运行中的 Host 管理频道和群组：重命名频道、设置群头像、邀请 Bot 或取消邀请、处理入群申请、移除成员、读取和设置唤醒策略、分页读取时间线和消息日志、标记已读、重试失败的私聊回复、查看历史，以及带 `--confirm` 预览并确认清除或删除群组（[#1698](https://github.com/BotHarness/DeepSeekBot/issues/1698)）。
