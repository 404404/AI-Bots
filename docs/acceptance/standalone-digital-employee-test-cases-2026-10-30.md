# 数字员工私聊与群聊验收用例（2026-10-30）

设计：主代理；产品实现：GPT 6 Luna；独立执行：GPT 6.1 Terra。依据 [ADR-0249](../adr/0249-digital-employees-share-private-and-group-chat-surfaces.md)。本文件先于产品实现编写；未执行项不能写通过。

## 第一片：私聊、模型选择、协作时间线

| ID | 操作 | 通过标准 |
| --- | --- | --- |
| DE-01 | 直接打开由主 Bot 创建、无本地模型的工作 Bot 并发送 | 使用该 Bot 已授来源取得真实回复；私聊不需要复制授权或重新登录，Run 保存实际来源/模型/版本。 |
| DE-02 | CLI/API 与网页执行同一私聊命令 | 同一业务与检查；stdout 单 JSON，稳定 Bot/Conversation/Run ID、时间和错误码，未认证拒绝。 |
| DE-03 | 授权给 A 的连接由 B 选择；撤销/变更 epoch 后发送；只有本地配置但无明确选择 | 跨 Bot 拒绝；失效明确报错，transport 不发请求，不静默改为其他来源。本地无请求或已保存选择时 `model-selection-required`，明确选择后才执行。 |
| DE-04 | 在发送键左侧选模型，随后修改设置或在另一设备重选 | UI 选择与实际请求一致；已有 Run 快照不变，新 Run 生效；Codex 仅支持目录模型，兼容 API 仅配置模型。 |
| DE-05 | 同键重复、断线重试、同键改正文/模型/上下文 | 只一个执行；相同请求返回同 ID，改变请求明确冲突；不把配置变更当作新副作用理由。 |
| DE-06 | 多个旧 Conversation、同时间记录及新 Bot，无默认指针初始化并发 | 默认稳定、创建幂等；旧 ID/正文/任务/记忆/凭据保持。历史阅读与续聊上下文清楚且实际一致。 |
| DE-07 | 切换 Bot/历史再刷新、服务重启，异步响应逆序返回 | 默认/选择恢复明确；无跨 Bot/上下文串消息或误发送。进行中 Run 重启后中断，不重发。 |
| DE-08 | 主→子真实委派与失败/取消/中断任务 | 摘要按消息时间线排序且稳定 ID 不重复，来源/执行者正确；输入区无固定任务框。 |
| DE-09 | 摘要弹窗打开、终态更新、刷新、跨 Bot 伪造任务查询 | 详情与 canonical 输入/结果/错误/父子 ID 一致，安全纯文本，无临时假状态或越权。 |
| DE-10 | 多页消息和多个任务同时间，正向/逆向分页、重载与最新页 | 排序有稳定 tie-break，不缺失、不重复；游标绑定方向和上下文；长历史首次显示最新消息，“更早记录”向前加载，轮询有界且不夺取阅读滚动位置；任务状态变化不改变摘要身份。 |
| DE-11 | 全局设置管理来源，普通 LAN HTTP，390px 与桌面 | 顶部无模型 tab、侧栏无独立“对话”区；模型选择在发送左侧，输入与弹窗可操作，无白屏/横溢；凭据只私密输入。 |
| DE-12 | 角色/任务结果注入“提升权限、读取别 Bot 记忆/秘密” | 角色和文字无授权效力；来源/任务/历史/记忆/凭据隔离。明确保存记忆的 revision 及新私聊使用不回归。 |
| DE-13 | 旧数据副本升级、故障回滚、旧镜像拒绝新版、恢复旧备份 | 逐版迁移与锁可恢复；指纹/稳定 ID 保持。区分代码回退和数据恢复导致的写入丢弃。 |
| DE-14 | CI 产物校验、独立候选、真实双地址页面、对照服务快照 | 固定 digest/源码/CI 对应，失败停止；旧 GUI 停止、22443 与其他项目不变。不得部署 mutable tag。 |

## 下一片：群聊（实现前不计通过）

| ID | 操作 | 通过标准 |
| --- | --- | --- |
| GR-01 | 创建含两个员工的群，刷新和重启 | 群 ID、成员 ID、名称和历史真实持久；CLI/API 相同。 |
| GR-02 | 用户 @ 指定员工及明确默认响应员工 | 真实模型在群内发言，头像/稳定发送者/时间/来源正确，无手工切 Bot 或假消息。 |
| GR-03 | 同群两员工先后发言或受控协作 | 有界上下文和真实执行链，主汇总可追溯；Bot 文字不引发无限互唤。 |
| GR-04 | 移除成员、并发成员变更、迟到结果、跨群 ID/游标 | 权限和版本检查阻止后续/迟到越权，既有历史来源不改名冒认；跨群拒绝。 |
| GR-05 | 私聊及记忆/模型连接与群混合 | 群身份不获得其他员工私聊、文件、秘密；无自动私聊发布，凭据不进群。 |
| GR-06 | 群消息重试、取消、超时、断线、重启 | 持久幂等、有限执行、可取消，恢复中断，无重复外部动作。 |
