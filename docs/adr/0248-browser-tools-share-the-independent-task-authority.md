# ADR-0248：浏览器工具复用独立任务权威

状态：Accepted（schema7 直接工具源码已接线；未部署、未通过真实浏览器验收；模型工具仍待实现）
日期：2026-10-30
范围：用户 fork 的 `standalone/`，补充 ADR-0246。

## 决策

浏览器执行器通过受限接口提供动作，应用持有对象权限及持久事实。执行器的单元测试、fixture 脚本和测试人员使用的 Chromium 均不能代替应用内工具交付。

### 传输与部署

GK50 优先使用只读挂载的私有 Unix socket 连接 worker。该 socket 是部署授予应用的受限能力，仅支持固定浏览器协议；不提供 shell、文件系统或容器管理。应用维持既有模型代理与 LAN 网络配置，不为浏览器改变宿主代理或开放控制端口。worker 仍使用无网络命名空间，经私有代理 socket 访问精确授权站点。网络 gateway 仅供受认证受限适配场景；不向 LAN 发布。

容器和映射均由 Compose 声明。应用、worker、proxy、fixture 的固定镜像身份分别记录；主应用不构建、启停或控制这些容器。控制通道不可用或沙箱检查失败时，工具明确拒绝，不能回退到主机浏览器或旧 DSH。

### 持久化与权限

同一 `bot.sqlite` 保存 browser session、step、截图资源及其 Bot/task 外键。`tasks` 继续拥有任务终态；browser session 只描述工具资源生命周期，不成为第二套任务权威。直接 owner CLI/API 可以创建一个无模型的浏览器任务并执行工具；模型工具只能使用当前可信工作任务的归属。所有者预先为指定 Bot 授予浏览器和精确 origin，模型/页面无修改授权的工具。

直接调用和模型调用进入同一 BrowserService，校验 Bot/task、允许动作、目标、预算、截止时间和状态。会话不接受调用参数伪造其他执行者，任务结果不包含服务密钥或宿主路径。截图由应用认证资源入口读取；模型仅得到有界页面文本、步骤状态和资源 ID，不能读取任意截图或跨 Bot 内容。

### 幂等和生命周期

会话及步骤先持久化接受事实，再调用 worker；操作 ID 和规范化参数摘要绑定当前对象。相同请求重放读回同一结果，不重复点击或输入；参数改变报冲突。发生不确定的传输失败或应用重启时标记 interrupted，不猜测动作是否发生，也不自动重发。

任务取消、终结和应用关闭通知 worker 关闭该任务的 context；worker 的短租约提供应用异常时的独立清理界限。迟到响应不能覆盖取消/中断。截图在 context 关闭前通过受限接口取回并保存为有界惰性 PNG，后续查看不要求保留活动浏览器。截图数量、单张及总字节、文本和步骤数均有明确硬上限。

工作模型使用实际 SDK 工具协议执行 browser 操作，最终子任务结果带来源返回主 Bot。页面文本和工具结果均为不可信数据；没有授权、凭据、上传、下载、登录或跨对象记忆写入工具。首个模型验收只使用隔离 fixture 页面和合成输入。

## 验收门禁

先完成 BW-01–08 的实际容器和直接 CLI/API，再验证 BW-09–10 的真实工作模型与主模型链。页面展示 canonical 会话、步骤、失败/中断及认证截图。模型 API 成功、worker 原型测试或截图存在不替代这一闭环。容器沙箱、网络隔离或必需真实模型项未通过时，不发布正式产品镜像。
