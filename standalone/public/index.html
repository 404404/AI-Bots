Bot 管理目录

按稳定 ID 区分 Bot。能力与执行状态来自当前实现和已保存的运行记录。

模型来源与私密登录

选择一个 Bot 配置它自己的模型来源或登录。已有凭据留在来源 Bot，不复制到授权员工。

设置主 Bot 模型

明确选择已有连接来源。主 Bot 使用服务端连接引用，不复制 OAuth 或 API 密钥。

授权主 Bot 委派

选择一个工作 Bot 和一个已有模型连接。只创建服务端引用，不复制来源凭据。

对话中的工作 Bot 管理

关闭时仍保留逐个 Bot 的现有委派授权；此策略只控制主 Bot 能否在对话中创建或修改工作 Bot。模型只能改名称和身份提示，不能改凭据、模型、授权或记忆。

Bot 身份

身份提示用于这个 Bot 的每次对话。

Bot 头像

仅支持非交错的 8 位 RGB/RGBA PNG（不支持灰度或调色板 PNG），输入不超过 2 MiB，尺寸不超过 1024×1024，总像素不超过 1,048,576；保存时会移除元数据并缩放到最长边 256 像素。

模型来源与私密登录

为选中的来源 Bot 配置模型。连接状态以实际回复为准。

尚未配置凭据

留空为直连。容器请使用 host.docker.internal，不要填宿主机的 127.0.0.1。代理不能保证解除服务端地区或账户限制。配置同时用于 Codex 登录、刷新和模型请求。

Codex 登录

尚未登录

使用独立登录记录，不读取旧 DSH 或 Codex CLI 凭据。此接入复用 pi-ai 的登录协议；刷新令牌轮换可能影响同一账户的其他会话。

在服务方页面完成登录

远程浏览器的 localhost 回调可能无法打开。完成服务方登录后，将地址栏完整回调地址私密粘贴于此，不要发到聊天中。

明确保存的文件记忆

只有保存的内容会带入新对话。每个 Bot 独立保存，最多 10 个文件、总计 24 KiB。
