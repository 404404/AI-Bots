## en

- **Settings → Data & privacy → Clear all BotHarness data** removes every Bot, chat, default-place Memory, attachment, workspace, IM connection setting and downloaded tool, so a reinstall starts fresh. It first lists exactly what is deleted and what stays (DSH credentials, Memory folders you chose, exported files), asks for a second confirmation, then restarts the Host. The same flow runs from `deepseekbot data-reset-preview` and `data-reset-confirm` ([#2426](https://github.com/BotHarness/DeepSeekBot/issues/2426)).

## zh

- **设置 → 数据与隐私 → 清除全部 BotHarness 数据**：删除所有 Bot、聊天记录、默认位置的记忆、附件、工作区、IM 连接设置和下载的工具，重新安装后从头开始。会先列出要删除和保留的内容（DSH 凭据、你选择的记忆文件夹、导出的文件），再次确认后重启 Host。CLI 用 `deepseekbot data-reset-preview` 和 `data-reset-confirm` 完成同样的流程（[#2426](https://github.com/BotHarness/DeepSeekBot/issues/2426)）。
