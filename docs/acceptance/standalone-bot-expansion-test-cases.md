### DG-01 的真实模型取证步骤

在候选中使用同源 Bot 稳定 ID 的合法独立模型连接，所有者分别为主 Bot 绑定引用、为测试工作 Bot 授予委派连接。确认主/工作 Bot 没有自己的 OAuth 行，源 Bot 的授权行没有因引用增加副本。

所有者为工作 Bot 的文件记忆保存一次性**非凭据**验收标记，主 Bot 输入不包含此标记；另在主 Bot 和未授权 Bot 的记忆/历史放不同非凭据哨兵。真实 LAN 网页要求主 Bot 按名称找到工作 Bot，让它读取自己的标记并计算本次指定的简单数值任务，取得结果后汇总。不得把标记、完整工作结果或任务完成状态预先填到主 Bot 输入中。

记录实际父子 UUID、worker 配置 revision、记忆 revision、真实工具调用 ID、子结果及主回复，核对主回复中的标记与子结果一致、来源与任务链对应。核对 worker 保存的受限输入/快照没有主和未授权 Bot 的哨兵。执行前后模型请求次数/持久任务计数与重试记录相符。模型与页面证据分别保存，任何失败均保留；不因输出看似正确而略过真实工具链。

## 第四片：自定义头像

实现前在文档固定支持格式、输入字节/像素/尺寸上限及输出格式；以下依该合同验收，不能仅按扩展名或声明 MIME 放行。

当前头像合同为 8 位 RGB/RGBA、非交错 PNG，输入至多 2 MiB、每边至多 1024 像素；输出重新编码并缩到最长边 256。调色板、灰度、16 位、交错或动画 PNG 属明确拒绝范围，网页和 CLI 文档需准确说明。独立测试至少解码正常输出像素，不能只检查 PNG 签名。额外覆盖上传读文件期间切换 Bot、替换/删除后现有导航及对话视图的旧 revision，以及 CLI 符号链接和读取增长边界。

| ID | 操作 | 验收事实 |
| --- | --- | --- |
| AV-01 | LAN 网页上传有效图片，查看列表、对话标题、管理/任务视图，再刷新与重启 | 同一 Bot 使用同一真实资源 revision；没有头像时明确默认占位；重启后仍读取持久资源。记录真实上传操作和图像文件身份。 |
| AV-02 | CLI/API 上传与读取；两 Bot 同时上传，再替换/删除其中一个 | 与网页共用存储和校验；另一 Bot 的资源不受影响；响应无本机路径，未登录请求不能读取；被删除 revision 不再作为当前头像。 |
| AV-03 | 有效图片伪造后缀/MIME、文本伪装 PNG、损坏/截断数据 | 按内容识别；拒绝不能解码内容；不因扩展名放行；失败保留原头像。 |
| AV-04 | SVG/HTML/script、路径穿越文件名、包含主动/附加内容的文件 | 拒绝主动格式或安全重编码为惰性位图；没有执行脚本、任意路径写入或原始主动内容回传；浏览器 console 无异常。 |
| AV-05 | 超字节、超尺寸/像素、异常压缩图片、并发解码 | 明确错误码，受限资源内完成/超时拒绝；应用健康且原头像未改变；边界等值和刚超过均测。 |
| AV-06 | 伪造 Bot ID/资源 ID/旧 revision、并发更换和删除 | 资源归属校验；只删除本对象的无引用文件；DB 当前引用与读回资源一致，不能误删他人资源。 |
