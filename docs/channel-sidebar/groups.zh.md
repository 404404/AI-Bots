# 成员与群管理

打开 **本地群聊 → Channel sidebar**。群 Channel 显示 **工作** 和 **成员**，不是某一个 Bot 的记忆、会话或工作区授权。**群管理** 是这个群 **频道设置** 中的分区：从聊天顶部的 **··· → 频道设置…**，或侧栏齿轮 **Channel sidebar 设置 → 频道设置…** 打开，弹窗标题为「_群名_ 群设置」。这些控件管理本地 BotHarness 群，不是 Lark、Slack 外部群的成员设置。

## 打开或创建群聊

从左侧列表打开现有群。创建时，使用 **新建 → 创建频道**，填写 **频道名称** 后点击 **创建**。新频道可以暂时没有 Bot；创建完成后再从侧栏邀请成员。

![真实本地教程群（旧版堆叠侧栏布局）](/guides/channel-sidebar/07-group-management-zh.webp)

## 查看群里的工作

**工作** 标签页列出这个群让 Bot 做的任务（Assignment），新的在前，分为四组：**等你处理**（最新报告在问你或被卡住）、**进行中**、**空闲**、**已结束**（完成、失败或已停止；默认收起，点开查看）。每行显示任务目的、最新报告摘要、负责的 Bot 和最近更新时间。点击一行会在 DSH 中打开该任务的会话。群里有新消息时列表会刷新。群里还没有任务时，标签页会用一句话说明。

## 管理成员

打开 **成员** 标签页（窄窗口覆盖面板中展开 **成员**），查看 Human、参与的 PersonaBot，以及存在时显示的创建者标记。点击 Bot 可打开私聊；它的 **…** 菜单包含 **打开私聊、消息提醒设置、移出群聊**，移出会要求确认。

点击标题旁的 **邀请新群员**，搜索可邀请 Bot 并发送邀请。已在群内、暂停或已有待处理邀请的 Bot 不会列为候选。邀请结果由 Profile 的 **自动接受入群邀请** 设置决定：开启时可以直接显示 **已接受**；关闭时等待 Bot 接受或拒绝。待接受邀请不等于已经入群，应核对邀请状态和实际成员列表。

**邀请与入群申请** 控件列出待处理和历史记录。可以取消待处理邀请，也可以批准或拒绝待审批入群申请。操作后核对成员列表，确认实际成员关系。

![真实邀请历史中已接受的示例 Bot](/guides/channel-sidebar/11-group-invitations-zh.webp)

## 选择成员提醒策略

使用 **管理 Bot → 消息提醒设置**，或在群的 **频道设置 → 唤醒策略** 分区中点击这个 Bot 的卡片。策略属于这个 Bot 在这个本地群中的配置。

| 选项         | 作用                                   |
| ------------ | -------------------------------------- |
| 每条消息     | 普通消息可以逐条唤醒 Bot。             |
| 仅直接 @     | 直接提及唤醒，普通群消息保持安静。     |
| 普通消息汇总 | 普通消息达到条数或最长等待时间后汇总。 |
| 静默收件     | 收到普通消息，但不因每条普通消息唤醒。 |
| 恢复继承     | 对这个群使用该 Bot 的 Profile 默认值。 |

使用汇总时，设置 **消息条数** 与 **最长等待（秒）**，再点击 **保存提醒设置**。已有来源路由与成员关系仍决定哪些消息会到达 Bot。阈值范围和 Bot 默认设置见[设置指南](/zh/docs/settings)。

![真实群内提醒设置的选项与汇总阈值](/guides/channel-sidebar/10-group-attention-zh.webp)

## 编辑群信息

打开 **频道设置… → 群管理**，修改群名后点击 **保存**；或选择 PNG／JPEG／WebP 头像，完成裁剪与保存。移除上传头像后会回到默认群图像。

**群管理更多操作 → 解散群聊** 会打开确认提示。它使成员失去这个群的访问权；隐藏左侧列表项目或关闭侧栏不会解散群。本教程展示管理界面，没有移出成员或解散示例群。
