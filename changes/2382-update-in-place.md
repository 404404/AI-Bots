## en

- **Update now** works again on DSH 0.2.1, whose Plugin Manager refused to overwrite an installed DeepSeekBot: the update now installs from the npm package tarball, applies in place and reloads the page without a restart. The upgrade notice is shorter, has an install button next to its title, and says in one line why an install failed, with the manual command. DeepSeekBot 1.4.1 and earlier still need one manual update ([#2382](https://github.com/BotHarness/DeepSeekBot/pull/2382)).

## zh

- 修复了 DSH 0.2.1 上 **立即更新** 失败的问题（DSH 插件管理拒绝覆盖已安装的 DeepSeekBot）：现在改用 npm 安装包地址原地升级，装好后页面自动刷新，无需重启。升级弹窗更简洁，标题旁新增安装按钮，失败时用一行说明原因并给出手动命令。DeepSeekBot 1.4.1 及更早版本仍需手动更新一次（[#2382](https://github.com/BotHarness/DeepSeekBot/pull/2382)）。
