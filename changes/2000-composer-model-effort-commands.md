## en

- Added inline `/model <text>` and `/effort <text>` pickers to a Bot DM composer: they list the same catalog models and reasoning efforts as the Bot's right-click menu, filter by the typed text, mark the current choice, and change only this Bot’s Orchestrator at the next turn, preserving fixed or inherited Assignment settings ([#2000](https://github.com/BotHarness/DeepSeekBot/issues/2000)).

## zh

- Bot DM 输入框新增内联 `/model <文本>` 与 `/effort <文本>` 选择器：列出与 Bot 右键菜单相同的模型和思考强度，按输入过滤、标记当前项，仅修改此 Bot 的 Orchestrator，在下一轮生效，保留 Assignment 固定配置或全局继承（[#2000](https://github.com/BotHarness/DeepSeekBot/issues/2000)）。
