## en

- Added a collapsible DeepSeekBot section with Bot/persona subgroups to the DSH Session list, keeping each Bot's Orchestrator and Assignment Sessions together across execution directories and using the configured Bot icon for the outer header ([#1997](https://github.com/BotHarness/DeepSeekBot/issues/1997)).
- Bot subgroup headers show their owning PersonaBot avatars instead of disclosure chevrons, while the whole header still toggles the group ([#1997](https://github.com/BotHarness/DeepSeekBot/issues/1997)).

## zh

- DSH 会话列表新增可折叠的 DeepSeekBot 分组，按 Bot／角色建立子组，集中收纳其 Orchestrator 与 Assignment 会话，支持不同执行目录；最外层标题使用用户设置的 Bot 图标（[#1997](https://github.com/BotHarness/DeepSeekBot/issues/1997)）。
- Bot 子组标题以所属 PersonaBot 的头像替换折叠箭头，点击整个标题仍可展开或折叠分组（[#1997](https://github.com/BotHarness/DeepSeekBot/issues/1997)）。
