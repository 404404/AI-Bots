## en

- Simplified ordinary Web tool approvals to Allow once, Always allow and Reject; Always allow applies immediately without a second confirmation and remembers the selected tool for this Bot in the current authority scope, including different inputs. Full Access automatically handles ordinary requests while permission changes can still reach a Human through native approval; existing rules and selected access scopes retain their meaning ([#2080](https://github.com/BotHarness/DeepSeekBot/issues/2080)).
