## en

- You can now move an existing Bot's memory files to another folder, or back to the default one, from the Bot's **Workspace Grants → Memory Repository** row. The Bot starts a new main session in the new folder; chats and Memory history stay. `deepseekbot memory-move <id> --memory-location <dir>` does the same from the command line ([#1772](https://github.com/BotHarness/DeepSeekBot/issues/1772)).

## zh

- 现在可以在 Bot 的 **工作区授权 → Memory Repository** 一栏，把已有 Bot 的记忆文件移到别的文件夹，或移回默认位置。移动后 Bot 会在新文件夹里开启新的主会话，聊天记录和记忆历史都会保留。命令行用 `deepseekbot memory-move <id> --memory-location <目录>` 达到同样效果（[#1772](https://github.com/BotHarness/DeepSeekBot/issues/1772)）。
