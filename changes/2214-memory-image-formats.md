## en

- Memory readers, version comparisons and Markdown images now support JPEG/JPG, GIF, WebP and bounded static SVG alongside PNG, with original-byte MIME-correct export; mobile readers use the same format and SVG safety policy ([#2214](https://github.com/BotHarness/DeepSeekBot/issues/2214)).
