## en

- The VRM companion Panel can be installed on its own as `@botharness/vrm-companion` with `dsh plugin add @botharness/vrm-companion`, once it is published to npm; it needs DeepSeekBot newer than 1.4.1 in the same Profile ([#2222](https://github.com/BotHarness/DeepSeekBot/issues/2222)).

## zh

- VRM 伴侣 Panel 可以作为独立包 `@botharness/vrm-companion` 安装，发布到 npm 后用 `dsh plugin add @botharness/vrm-companion` 即可；同一 Profile 中需要安装 1.4.1 之后的 DeepSeekBot（[#2222](https://github.com/BotHarness/DeepSeekBot/issues/2222)）。
