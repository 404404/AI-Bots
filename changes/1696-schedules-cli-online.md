## en

- The `deepseekbot schedules`, `schedule-create`, `schedule-update`, `schedule-preview`, `schedule-run-now`, `schedule-history` and `schedule-delete` commands now work against a running Host, with the same checks as the Schedules panel and the Host's own error codes. `schedule-delete` needs `--confirm` ([#1696](https://github.com/BotHarness/DeepSeekBot/issues/1696)).

## zh

- `deepseekbot schedules`、`schedule-create`、`schedule-update`、`schedule-preview`、`schedule-run-now`、`schedule-history` 和 `schedule-delete` 现在可以直接操作运行中的 Host，检查与「定时任务」面板相同，并返回 Host 自己的错误码。`schedule-delete` 需要 `--confirm`（[#1696](https://github.com/BotHarness/DeepSeekBot/issues/1696)）。
