# KayKit furniture subset

Author: Kay Lousberg. Pack: KayKit Furniture Bits 1.0. License: CC0, original `LICENSE.txt` retained.

Source: https://github.com/KayKit-Game-Assets/KayKit-Furniture-Bits-1.0/tree/main/addons/kaykit_furniture_bits/Assets/gltf

Shipped: `book_set.gltf` / `.bin`, `shelf_B_small_decorated.gltf` / `.bin`, and their shared `furniturebits_texture.png`. Source bytes are unchanged; runtime applies scale/placement and roughness. Build-time embedding makes the existing Client self-contained without an external asset route.

`inspection.json` preserves exact downloaded source URLs, SHA-256, sizes and accessor inspection. It also lists `lamp_table` and `armchair_pillows`, which were evaluated but are **not shipped or loaded**. The selected two models total 728 triangles before scene instancing.
