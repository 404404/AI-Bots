## en

- You can now run a Bot's Computer tools directly from the CLI, without the model: `deepseekbot computer-tools` lists the curated tools and `computer-tool <bot> <tool> --args-stdin [--out <file>]` runs one through the same driver call, Computer Access check and audit a Bot uses ([#1682](https://github.com/BotHarness/DeepSeekBot/issues/1682)).

## zh

- 现在可以绕过模型、直接用命令行执行 Bot 的 Computer 工具：`deepseekbot computer-tools` 列出经过筛选的工具，`computer-tool <bot> <tool> --args-stdin [--out <file>]` 通过 Bot 使用的同一个驱动调用、同样的 Computer 权限检查和审计执行其中一个（[#1682](https://github.com/BotHarness/DeepSeekBot/issues/1682)）。
