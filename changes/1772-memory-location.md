## en

- When creating a Bot, **Advanced settings → Memory location** lets you keep its memory files in a folder you choose, such as another drive, instead of the default DSH data folder. `deepseekbot create --memory-location <dir>` does the same from the command line ([#1772](https://github.com/BotHarness/DeepSeekBot/issues/1772)).

## zh

- 创建 Bot 时，可以在 **进阶设置 → 记忆文件位置** 选择记忆文件存放的文件夹（例如另一块磁盘），不必放在默认的 DSH 数据目录。命令行用 `deepseekbot create --memory-location <目录>` 达到同样效果（[#1772](https://github.com/BotHarness/DeepSeekBot/issues/1772)）。
