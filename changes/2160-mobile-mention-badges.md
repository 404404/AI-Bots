## en

- Mobile chats retain structured Bot mentions and display leading mentions with the current name and avatar. Tap a mention to open that Bot's DM; renamed or missing Bots are resolved by ID rather than display name ([#2160](https://github.com/BotHarness/DeepSeekBot/issues/2160)).

## zh

- 移动端聊天保留结构化 Bot 提及，并以当前姓名和头像显示开头的提及块。点击可打开对应 Bot 的私聊；改名或缺失的 Bot 按 ID 识别，不通过显示名称匹配（[#2160](https://github.com/BotHarness/DeepSeekBot/issues/2160)）。
