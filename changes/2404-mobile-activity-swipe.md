## en

- On the phone, swipe an Activity reply or unread conversation left to clear it, like working through an inbox; an undo bar brings it back, and desktop Activity hides it too. Requests that need you can only be put off until later (tomorrow 9:00 on a full swipe, or pick a time), and Needs you now shows the newest first. Filters → Cleared and Snoozed list what you set aside so you can restore it; `deepseekbot inbox --dismissed` and `deepseekbot inbox-restore` do the same from the CLI ([#2404](https://github.com/BotHarness/DeepSeekBot/pull/2404)).

## zh

- 手机端 Activity 中，向左滑动回复或未读会话即可清理，像逐封处理收件箱一样；底部撤销条可以恢复，桌面端 Activity 也会同步隐藏。需要你处理的请求只能"稍后提醒"（滑到底为明天 9:00，也可以选时间），"需要你"现在默认最新的在最上面。筛选 → 已清理 / 已稍后 可以查看并恢复被放到一边的条目；CLI 可用 `deepseekbot inbox --dismissed` 和 `deepseekbot inbox-restore` 完成同样的操作（[#2404](https://github.com/BotHarness/DeepSeekBot/pull/2404)）。
