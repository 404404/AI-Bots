## en

- Memory files, Memory evolution and Schedules now open inside Messages and remember their position, proportion and visibility separately for each Bot Channel. Existing layouts and shortcuts are preserved; a child shortcut restores its hidden parent ([#2067](https://github.com/BotHarness/DeepSeekBot/issues/2067)).

## zh

- 记忆文件、记忆演化和定时任务现位于消息面板内部，分别按 Bot 频道记住位置、比例和开关。保留旧布局与快捷键，子面板快捷键可恢复隐藏的消息父面板（[#2067](https://github.com/BotHarness/DeepSeekBot/issues/2067)）。
