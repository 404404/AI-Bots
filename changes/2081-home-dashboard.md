## en

- Home shows pending attention, currently working Bots, precise rolling token usage and recently active Channels/tasks without a model report. Each card keeps unavailable or partial data visible; activity opens its existing conversation or task. The matching `home-dashboard` CLI reads the same facts ([#2081](https://github.com/BotHarness/DeepSeekBot/issues/2081)).

- Owned approval and question requests reach their Channel owner before generic native UI forwarding, while unowned requests keep their native fallback ([#2081](https://github.com/BotHarness/DeepSeekBot/issues/2081)).

## zh

- Home 展示待处理事项、正在工作的 Bot、精确滚动时间段内的 Token 用量和最近活跃的频道／任务，无需生成模型报告。各卡片保留不可用或部分数据状态，活动可打开既有对话或任务；`home-dashboard` CLI 读取相同事实（[#2081](https://github.com/BotHarness/DeepSeekBot/issues/2081)）。

- 已归属 Bot 的审批和提问先交给频道所有者呈现，未归属请求继续使用原生界面回退（[#2081](https://github.com/BotHarness/DeepSeekBot/issues/2081)）。
