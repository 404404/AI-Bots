## en

- Added readable global recovery controls for DeepSeekBot appearance: clear only the current mode's Panel overrides, or explicitly confirm resetting both modes and removing wallpaper. Recovery reports partial media cleanup failures and supports retry through the same UI and targeted CLI without changing layout or DSH preferences ([#2264](https://github.com/BotHarness/DeepSeekBot/issues/2264)).

- Replaced message-history edge color overlays with an alpha mask so custom Panel colors and wallpaper remain visible ([#2264](https://github.com/BotHarness/DeepSeekBot/issues/2264)).

## zh

- DeepSeekBot 全局外观新增可读的恢复入口：仅清除当前模式全部面板覆盖，或明确确认后恢复两套默认外观并移除壁纸。媒体清理失败会说明已完成的部分，可通过同一界面及定向 CLI 重试，不改变布局或 DSH 偏好（[#2264](https://github.com/BotHarness/DeepSeekBot/issues/2264)）。

- 消息历史上下边缘改用透明度遮罩渐隐，保留自定义面板底色和壁纸，移除固定底色覆盖（[#2264](https://github.com/BotHarness/DeepSeekBot/issues/2264)）。
