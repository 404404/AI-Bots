## en

- The DeepSeekBot mobile app now paints with the same DSH colours as the Web Client, and its chat bubbles use the platform text sizes and the shared spacing and radius scale. In a DM, the Human's bubble takes that Bot's primary colour. `apps/mobile/DESIGN.md` sets the app's structure (Hosts as workspaces; Home, Activity and Me tabs; action cards in the chat) and the code rules a test now enforces ([#1643](https://github.com/BotHarness/DeepSeekBot/issues/1643)).

## zh

- DeepSeekBot 手机 App 改用与 Web 端相同的 DSH 配色，聊天气泡改用平台原生字号和统一的间距、圆角刻度。私聊中用户气泡的底色改为该 Bot 的主色。新增 `apps/mobile/DESIGN.md`，规定 App 的结构（Host 即 workspace；首页、动态、我三个 Tab；对话流内的操作卡片），以及由测试守护的代码规则（[#1643](https://github.com/BotHarness/DeepSeekBot/issues/1643)）。
