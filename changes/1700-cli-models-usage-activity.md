## en

- Agents can manage models and read usage and activity from the `deepseekbot` CLI against a live Host: `model-catalog`, `model-plan-set`, `model-plan-customize`, `model-plan-inherit`, `model-plan-assignments-set` and `model-preset-update` change a Bot's model plan or a preset with the same checks as the Web UI, and `overview-usage`, `overview-memory`, `activity-overview`, `channel-activity-today`, `bot-usage`, `bot-session-usage`, `bot-activity-history` and `group-activity` read the Overview page and the Profile and group panels as JSON ([#1700](https://github.com/BotHarness/DeepSeekBot/issues/1700)).

## zh

- Agent 可以通过 `deepseekbot` CLI 连接运行中的 Host 管理模型并读取用量和活动：`model-catalog`、`model-plan-set`、`model-plan-customize`、`model-plan-inherit`、`model-plan-assignments-set` 和 `model-preset-update` 以与 Web UI 相同的校验修改 Bot 的模型方案或预设，`overview-usage`、`overview-memory`、`activity-overview`、`channel-activity-today`、`bot-usage`、`bot-session-usage`、`bot-activity-history` 和 `group-activity` 以 JSON 形式读取总览页以及 Profile 和群组面板的数据（[#1700](https://github.com/BotHarness/DeepSeekBot/issues/1700)）。
