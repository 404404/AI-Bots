## Description

```
DeepSeekBot is the open-source Grok Bot alternative, based on DeepSeek Harness (DSH). It runs on DSH's own session management and harness, so you can use any LLM provider you connect in DSH. It installs as one DSH plugin alongside your other DSH plugins (if one doesn't play well with it, Issues and PRs are welcome), and it is MIT licensed.

It is a crew of bots, each with its own identity, persona and memory:
• Message your bots and hand them work like teammates. Mention one in a Group and it picks up; several can work at once.
• Talk to people, not sessions: create a virtual teammate and just ask.
• Lives in Lark / Feishu, Slack, Discord and WeChat, under each bot's own identity, replying right in the original thread.
• Memory is Git: preferences, projects and conversations are plain files. Open branches, commits and diffs any time, go back when it gets something wrong, or push to GitHub to share one memory across machines.
• Grant a Workspace and a bot can delegate independent Assignments, each with its own report.
• Every bot gets a pixel face from its name, and morphs into the tool it is using while it works.
```
