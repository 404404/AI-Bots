## en

- Tob can cancel pending group invitations and accept or decline pending join requests through reviewed CLI operations, with current access and target checks. Default automatic acceptance is unchanged; cancelling an invitation never removes an existing member ([#2090](https://github.com/BotHarness/DeepSeekBot/issues/2090), [CLI guide](../docs/bot-cli.md#tob-invitation-cancellation-and-join-decisions)).

## zh

- Tob 可通过经审核的 CLI 操作取消待处理群邀请，或接受、拒绝待处理入群申请，并校验当前权限与目标。默认自动接受邀请不变，取消邀请不会移除已入群成员（[#2090](https://github.com/BotHarness/DeepSeekBot/issues/2090)、[CLI 指南](../docs/bot-cli.md#tob-invitation-cancellation-and-join-decisions)）。
