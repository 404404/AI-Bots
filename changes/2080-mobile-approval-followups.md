## en

- Focusing the reply field on an Assignment from Activity now scrolls Send above the keyboard too ([#2080](https://github.com/BotHarness/DeepSeekBot/issues/2080)).
- Tool approvals in Activity use the short "Use …" line, so the row no longer cuts it to "Requests…" ([#2080](https://github.com/BotHarness/DeepSeekBot/issues/2080)).
- A decided tool approval in the chat names the command it ran, such as `gh --version`, instead of only the tool ([#2080](https://github.com/BotHarness/DeepSeekBot/issues/2080)).
- Screen readers no longer read an empty ", ." for Activity items without a summary, such as group join requests ([#2080](https://github.com/BotHarness/DeepSeekBot/issues/2080)).

## zh

- 从动态页打开 Assignment 后，点进回复框时，发送按钮也会一起滚到键盘上方（[#2080](https://github.com/BotHarness/DeepSeekBot/issues/2080)）。
- 动态页里的工具审批改用更短的“使用 …”文案，不会再被截成 “Requests…”（[#2080](https://github.com/BotHarness/DeepSeekBot/issues/2080)）。
- 聊天里已处理的工具审批会显示当时运行的命令（例如 `gh --version`），不再只显示工具名（[#2080](https://github.com/BotHarness/DeepSeekBot/issues/2080)）。
- 没有摘要的动态（例如群组加入申请）不会再让读屏念出空的 “, .”（[#2080](https://github.com/BotHarness/DeepSeekBot/issues/2080)）。
