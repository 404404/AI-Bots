## en

- Dismissing a Panel header context menu with Escape returns keyboard focus to that header, keeping subsequent keyboard navigation in the Panel ([#2017](https://github.com/BotHarness/DeepSeekBot/issues/2017)).

## zh

- 按 Escape 关闭面板标题的右键菜单后，键盘焦点返回该标题，后续键盘导航保持在面板内（[#2017](https://github.com/BotHarness/DeepSeekBot/issues/2017)）。
