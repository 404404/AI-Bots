## en

- In the DeepSeekBot mobile app, the **Computer** button of a Bot that uses this computer now opens a native screen showing the desktop live. **Take control** lets you click, scroll and type on it from the phone, for example when the Bot asks for help with a login. The new `deepseekbot computer-frame` and `computer-input` commands do the same from a terminal ([#1832](https://github.com/BotHarness/DeepSeekBot/issues/1832)).

## zh

- DeepSeekBot 手机 App 里，使用本机 Computer 的 Bot 的**Computer**按钮现在会打开原生界面，实时显示桌面。点**接管**后可以在手机上点击、滚动和输入，例如 Bot 请你帮忙登录时。新的 `deepseekbot computer-frame` 和 `computer-input` 命令可以在终端做同样的事（[#1832](https://github.com/BotHarness/DeepSeekBot/issues/1832)）。
