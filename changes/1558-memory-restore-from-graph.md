## en

- Memory evolution can restore Memory to any Git graph commit from inside that commit's block, after saving any uncommitted files as a backup commit; any commit can be given a version name, stored as a Git tag, and Memory evolution can switch to a list of named versions; the restore adds a new commit, the Memory file list refreshes right away, and the recovery list moves to Advanced · System snapshots ([#1558](https://github.com/BotHarness/DeepSeekBot/pull/1558)).

## zh

- 记忆演化可以在 Git 图的任意提交方块里「恢复到这次提交」：未提交的改动先自动存成一个提交，任意提交都能用 Git tag 起个版本名，记忆演化可切换为已命名版本列表，再以新提交恢复所选记忆，记忆文件列表随即刷新；原恢复检查点列表收进「高级 · 系统快照」（[#1558](https://github.com/BotHarness/DeepSeekBot/pull/1558)）。
