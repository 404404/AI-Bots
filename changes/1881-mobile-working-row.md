## en

- In the DeepSeekBot mobile app, a working Bot now shows at the bottom of the message list, like in the Web Client, instead of in a strip above the composer, so the composer no longer jumps when a Bot starts or stops; in a group Channel each working Bot gets its own line and Stop ([#1881](https://github.com/BotHarness/DeepSeekBot/pull/1881)).

## zh

- DeepSeekBot 手机 App 里正在工作的 Bot 现在和 Web 客户端一样显示在消息列表底部，不再固定在输入框上方，Bot 开始或停止工作时输入框不会再跳动；群聊里每个正在工作的 Bot 各占一行，可以分别停止（[#1881](https://github.com/BotHarness/DeepSeekBot/pull/1881)）。
