# GUI container security refresh

The first post-approval candidate, [CI run 40702391843](https://github.com/404404/AI-Bots/actions/runs/40702391843), built successfully but failed Trivy. The GUI runtime gate and publication did not execute. This failure is independent of the earlier Chromium syscall-policy refusal.

## Located causes and changes

The fix is [commit 7d94b259](https://github.com/404404/AI-Bots/commit/7d94b259629fbbac5a401f18a525d5542c30f1e5). It changes only `deploy/Dockerfile`, `pnpm-workspace.yaml` and `pnpm-lock.yaml`.

| Location                                            | Finding                                                                                                          | Remediation                                                                                                                                                                                                                                                          |
| --------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Runtime Debian packages                             | Cached Chromium 155.0.8059.79 and vulnerable Brotli/OpenSSL packages                                             | Refresh the package-install layer and apply available security updates on the same pinned Node base image. The scan identified Chromium 156.0.8078.47, Brotli 1.0.9-2+deb12u1 and OpenSSL 3.0.22-1~deb12u2 as fixed candidates. The resulting image must pass Trivy. |
| Application and independently installed DSH Profile | Vulnerable body-parser 2.3.0; undici 6.29.0, 7.29.1 and 8.11.2; Zod 4.4.3/4.6.5                                  | Pin compatible major-specific overrides to body-parser 2.4.0, undici 6.29.1/7.30.1/8.12.2 and Zod 4.6.6, then regenerate the lock. The Profile inherits these overrides.                                                                                             |
| npm bundled HTTP client                             | npm 12.2.1 carries vulnerable undici 6.29.0                                                                      | Replace that vendored client with the patched 6.29.1 release while retaining npm 12.2.1.                                                                                                                                                                             |
| Build-only Mermaid/Puppeteer chain                  | Chromium BiDi retains Zod 3.25.76 in the runtime image although that chain is used only for documentation builds | Remove the Mermaid/Puppeteer/Chromium BiDi build-tool chain and its Zod 3 copy from the runtime image. Keep the distinct `@puppeteer/browsers` runtime package, Playwright, DSH and YAML. Do not force Zod 3 consumers onto Zod 4.                                   |

No vulnerability ignore entry or weaker scanner threshold was added. The production Chromium sandbox policy and dropped capabilities are unchanged by this dependency refresh. Publication still requires the production runtime gate and pushes the image tested by that gate; it does not build another image for publication.
