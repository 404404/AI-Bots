## en

- Added the to-do example plugin's Host part, `@botharness/todo`: a shared to-do list kept in DSH storage, Bot tools (`todos_list`, `todos_add`, `todos_update`, `todos_remove`) that let a PersonaBot track things for the Human, and `deepseekbot todos` / `todo-*` commands that read and change the list or run a tool without the model. Its To-do Dock panel follows in a later release ([ADR-0203](../docs/adr/0203-bot-mode-is-a-dockable-layout-that-plugins-extend-with-dock-panels.md), [#1792](https://github.com/BotHarness/DeepSeekBot/issues/1792)).

## zh

- 新增待办示例插件 `@botharness/todo` 的 Host 部分：一个保存在 DSH 存储中的共享待办列表；Bot 工具（`todos_list`、`todos_add`、`todos_update`、`todos_remove`），让 PersonaBot 替 Human 记录和跟进事项；以及 `deepseekbot todos` / `todo-*` 命令，用于读取和修改列表，或绕过模型直接运行工具。待办 Dock 面板将在后续版本提供（[ADR-0203](../docs/adr/0203-bot-mode-is-a-dockable-layout-that-plugins-extend-with-dock-panels.md)，[#1792](https://github.com/BotHarness/DeepSeekBot/issues/1792)）。
