# DeepSeekBot 1.2.1 candidate qualification

This is a release candidate, not an npm publication or a Human-QA approval.

## Bounded contents

The maintenance base is v1.2.0 (`271e056aecd7f10bd71128a78d2ac9acbea898ea`).
Reviewed UI backports are Group member avatar stacks (#1270 / PR #1273), compact audio/file
cards (#1290 / PR #1294), and mirrored own-message headers (#1298 / PR #1299).
The stack uses the 1.2 Avatar contract, without importing 1.3 seeded-face APIs.
No 1.3 schema migrations are included. A previously merged macOS test-fixture path correction
(PR #1336) is test-only; it does not change Profile Backup behavior.

Core, UI, the product Bundle and product-managed IM Provider declare `>=0.1.7-0`.
There is no future Host ceiling. Native preflight checks hypothetical 1.0/2.0 versions;
those assertions prove metadata acceptance only, not future runtime compatibility.
Independent Browser/Computer Bundles and non-DSH peers retain their own contracts.

The Provider artifact is `4.32.0-botharness.16`, derived from the unchanged `.15` source
`36da305c9586335a47d4bab6ee4f0025247a9d8f` and immutable runtime digest. Main's newer Provider
source is deliberately not backported.

## Evidence boundaries

- [Sanitized installation matrix](evidence/1425-install-matrix.json): all eight published
  versions pass real four-tarball Profile installation/composition, authenticated API creation
  of a synthetic Bot/DM, and restart persistence, without exemptions. Package integrities bind
  this result to candidate bytes, not to a future registry publication.
- Native DSH 0.2.0-rc.2 browser capture shows a real synthetic Group, audio/file cards and
  message header before/after. Audio reaches ready state 4 with one-second duration and its
  Play control was exercised. This is not native IM delivery or physical Desktop/platform QA.
- Local full suite: 426 files / 3,493 tests pass, five files / nine tests skip, with four workers
  and a 60-second timeout. Default 15-second full runs had contact-discovery/DM-steering
  timeouts; both files pass an isolated default-timeout run (15 tests). Do not label the
  default-timeout full run green. Later focused launcher/release-gate tests are separate.
- Lint, formatting, types, build and bilingual ledgers are checked locally. Exact-head CI,
  Human QA, npm publication/integrity readback and live site deployment remain separate gates.
