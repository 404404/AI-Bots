## en

- The mobile app now handles the remaining requests that used to need the desktop: allow an auto-rejected call once, accept or decline a Bot's group join request, and reply to an Assignment that is waiting on you or blocked so it resumes. These requests also send phone notifications (approvals and access requests, or questions and Assignments). A private input request now shows a card in chat that opens the secure form in the full client on the phone. Tool approvals on the phone now show a file edit as a diff with its line counts, the expiry when it is under an hour, a waiting or interrupted Assignment, and the same risk warnings as the Web card ([#2080](https://github.com/BotHarness/DeepSeekBot/issues/2080)).

## zh

- 手机端现在可以处理之前必须回到电脑的请求：对被自动拒绝的调用“仍然允许这一次”、同意或拒绝 Bot 的入群申请、回复等待你或受阻的 Assignment 让它继续。这些请求也会推送到手机（归在“审批与授权请求”或“提问与 Assignment”）。私密输入请求在聊天里显示卡片，可直接在手机上的完整客户端打开安全填写页。手机上的工具审批也会像网页一样显示文件改动 diff 和行数、一小时内的过期时间、Assignment 等待或中断状态，以及相同的风险提示（[#2080](https://github.com/BotHarness/DeepSeekBot/issues/2080)）。
