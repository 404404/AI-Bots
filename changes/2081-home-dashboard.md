## en

- Home shows pending attention, currently working Bots, precise rolling token usage and recently active Channels/tasks without a model report. Each card keeps unavailable or partial data visible; activity opens its existing conversation or task. The matching `home-dashboard` CLI reads the same facts ([#2081](https://github.com/BotHarness/DeepSeekBot/issues/2081)).
