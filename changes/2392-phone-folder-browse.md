## en

- On a computer that opens its own folder dialog, the phone can now browse the computer's folders to grant one to a Bot, instead of typing a path. Folder names only are listed; `deepseekbot folder-browse` lists the same folders ([#2392](https://github.com/BotHarness/DeepSeekBot/pull/2392)).

## zh

- 电脑使用系统自带的文件夹选择器时，手机现在也能浏览电脑上的文件夹，选一个授权给 Bot，不必再手动输入路径。只列出文件夹名称；`deepseekbot folder-browse` 可列出同样的文件夹（[#2392](https://github.com/BotHarness/DeepSeekBot/pull/2392)）。
