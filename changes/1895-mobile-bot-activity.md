## en

- In the DeepSeekBot mobile app, a Bot's profile shows its last 7 days: the token total with a bar per day, and a small row of events and Memory commits. Tapping it opens Activity, where you can switch between 7 days, 4 weeks and 6 months, page back to earlier periods, and see the cache read, input and output split, usage by model, events by reason and a Memory commit heatmap, with the same numbers as the Web Client ([#1895](https://github.com/BotHarness/DeepSeekBot/issues/1895)).

## zh

- DeepSeekBot 手机 App 的 Bot 资料页会显示近 7 天的情况：Token 总用量和每天一根柱子，以及一行事件和 Memory 提交。点它会打开「活跃情况」，可以在 7 天、4 周和半年之间切换、往前翻到更早的时间段，查看缓存读、输入和输出的拆分、按模型的用量、按来源的事件和 Memory 提交热力图，数字与网页客户端一致（[#1895](https://github.com/BotHarness/DeepSeekBot/issues/1895)）。
