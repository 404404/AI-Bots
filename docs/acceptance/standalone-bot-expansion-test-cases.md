# 独立 Bot 扩展验收用例（主代理编写）

执行者：GPT 6.1 Terra。产品代码与修复：GPT 6 Luna。所有结论区分通过、失败、部分验证/未覆盖、外部条件阻塞、未实现。不得输出访问码、cookie 或任何模型授权。旧 DSH 保持停止，只操作本项目的新测试目录/容器。普通 LAN HTTP 页面、API、模拟协议与真实模型证据各自标明。

## 第一片：主 Bot 身份和直接管理

| ID | 操作 | 验收事实 |
| --- | --- | --- |
| MB-01 | 空目录初始化、重复打开、并发进程拒绝、重启 | 同一主 UUID；恰好一个主 Bot；原 owner 锁有效，不重复创建。 |
| MB-02 | 合成 v1 数据包含正常 Bot、同名“主 Bot”和保留 slug 冲突；迁移后再打开 | 原 IDs、身份、历史、记忆和加密合成凭据保持；唯一主身份由 singleton 指定，不采用已有名称。 |
| MB-03 | 不兼容 schema、损坏 singleton/引用、迁移故障与备份恢复 | 明确错误并停止；无部分提交，不以新 Bot 掩盖损坏；v1 代码拒绝 v2 数据，恢复 v1 备份后原代码/数据可用。仅实验目录。 |
| MB-04 | 真实 LAN 登录，主入口、目录、选择/创建/编辑工作 Bot，刷新与候选重启 | 固定主入口指向 canonical UUID；目录反映真实名称/角色/实现能力/执行状态；能进入真实设置与持久化，不假造委派状态。 |
| MB-05 | 两 Bot 同名、中文/HTML名称、重命名、空/超长输入 | UI 纯文本、ID/slug可区分；原历史/记忆归属不变；拒绝输入不覆盖原值；主名称变化仍保持主 UUID。 |
| MB-06 | 身份提示自称主/管理员、传 isMain/actor/权限字段、非 owner 执行上下文尝试管理 | 不能授予主身份或 owner 权限；持久化角色提示与授权分开；无凭据/其他 Bot 内容泄漏。 |
| MB-07 | 先提交运行，再编辑名称/角色，检查运行配置版本与后续执行 | 已有运行绑定提交时 revision/非秘密配置；后续运行使用更新值；旧 Run 不被改写。真实角色回复沿用独立验收另测，不用保存成功顶替。 |
| MB-08 | 真实 CLI main.get/main.catalog，读/写既有 Bot，分页、错误码、未认证拒绝 | 单一 JSON、同 UUID/时间戳/游标和业务权限；Web/CLI共用 owner；模型参数不能伪造执行上下文。 |
| MB-09 | 独立清洁构建/运行、产物和 import 检查、候选 Compose 与环境快照 | 无 DSH/Cordis/旧 Host；候选端口/数据独立；生产原数据、旧 GUI 和其他服务不变；固定源码/镜像身份可追溯。 |

第一片通过后提供可体验入口、截图/ARIA/console、canonical IDs 和逐项结果。测试浏览器只作为测试设备，不算产品浏览器。

## 第二、三片：真实委派与任务生命周期

前置：第一片通过；所有测试使用独立数据。真实模型只用用户已有独立产品的合法授权，不能复制到另一个 Bot。测试连接共享必须通过待实现的所有者授权引用功能。测试任务仅产生测试数据，无第三方消息/交易。

| ID | 操作 | 验收事实 |
| --- | --- | --- |
| DG-01 | 所有者授权主 Bot 的协调范围、连接引用和一个工作 Bot；主 Bot 提交独特标记任务 | 模型协议真实调用委派工具；持久子任务执行实际模型；主 Bot 再次模型调用读取真实工具结果并回复；父子 ID、执行者、来源和结果互相对应。分别保存脱敏协议轨迹、canonical 查询和 LAN UI 证据。 |
| DG-02 | CLI/API 直接创建相同任务；重复幂等键、丢失响应后重试、同键不同参数 | 与模型工具共用业务/权限；相同操作返回同一任务，模型请求计数和副作用计数不增加；冲突明确拒绝。工具调用 ID 复用也覆盖。 |
| DG-03 | 主 Bot 对话创建并配置工作 Bot，再委派；两 Bot 同名并重命名 | 创建/更新是真实工具调用；只用已授权连接/允许配置字段；按稳定 ID 委派；配置修订和已有任务快照可追溯；UI 显示可区分来源。 |
| DG-04 | 未授权/撤销连接、伪造连接来源、主身份或角色提示、跨 Bot secret 访问 | 明确拒绝且无模型请求；凭据行数/归属不因共享增加；消费者无法取回源 secret；禁止读取源历史/记忆。撤销后的新调用停止，不回退到其他连接。 |
| DG-05 | 子任务返回诱导授权/泄露/写记忆指令；主/工作 Bot 角色声明管理员；工具参数伪造执行者/根/祖先 | 服务端作用域不变，无额外授权或跨对象读写；独特秘密哨兵不出现在提示/结果/日志；任务输出被标为不可信来源数据。 |
| TS-01 | 同时提交超过并发上限的根/子任务，父等待子 | 活动数不越界；排队有真实持久状态；无父任务占满槽导致的死锁；总任务/工具预算稳定。 |
| TS-02 | A→A、主→工作→主、超深链和耗尽工具预算 | 深度/祖先/目标策略拒绝，无无限唤醒；错误归属于真实 task/tool；普通文本 JSON 不触发工具。 |
| TS-03 | 活动模型期间取消父/子、排队期间取消，迟到返回 | cancelled 先持久化；中断实际请求；传播关系清楚；迟到返回不覆盖终态，无 assistant 或其他副作用写入。真实取消与受控模拟分别记录。 |
| TS-04 | 模型 401/403/429/无效响应、代理不可达、任务截止超时 | 失败/超时状态及子错误能回到主和页面；错误不含 raw response/secret；不悄然直连或自动重复副作用。 |
| TS-05 | 混合 completed、未开始、活动任务时停止/强杀候选再启动 | completed 保持，未终结按 ADR 标 interrupted，不盲目重发；真实请求/测试副作用计数无额外增加；用户明确新操作可关联原 task 重试。 |
| TS-06 | 逐一用 Bot A 执行上下文访问 B 的 conversation/run/task/memory/credential/browser 资源 | 同源业务拒绝矩阵逐格记录；不存在与不属于自己均无内容泄漏；所有者获准的目录/任务汇总不等于工作 Bot 全局权限。 |
| TS-07 | LAN 网页提交任务、断线重连、取消、失败、展开父子轨迹 | 持久 task 状态与页面状态一致；重连无重复提交；刷新保留来源；UI 无未处理异常；凭据与登录信息不出现在证据。 |

真实模型 DG-01 和 DG-03 未通过时，模拟测试仅计协议/业务覆盖，不能宣布委派已交付。

- DG：主→一个工作 Bot→主的真实回复和 task 父子来源；受限上下文与 owner 显式共享连接引用；模型工具及 CLI/API 共用权限/执行实现。
