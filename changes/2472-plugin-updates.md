## en

- **Bot settings → Plugins** lists installed BotHarness plugins such as VRM Companion with their version, checks npm for a compatible update and installs it in one click, reloading the page or offering **Restart now** when the update needs a restart. The same flow is available as `deepseekbot plugin-check`, `plugin-install` and `plugin-restart` ([#2472](https://github.com/BotHarness/DeepSeekBot/pull/2472)).

## zh

- **Bot 设置 → 插件** 会列出已安装的 BotHarness 插件（例如 VRM 伴侣）和它们的版本，从 npm 检查兼容的新版本并一键更新；更新装好后自动刷新页面，需要重启时会提供「立即重启」。同样的流程也可以用 `deepseekbot plugin-check`、`plugin-install` 和 `plugin-restart` 完成（[#2472](https://github.com/BotHarness/DeepSeekBot/pull/2472)）。
